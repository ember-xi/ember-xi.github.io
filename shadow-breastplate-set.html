Shadow Breastplate Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

This set has an HQ version, Valkyrie's Breastplate Set. The Shadow Breastplate Set is a heavy armor set with high amounts of HP, MP, Accuracy, and Attack. The set is acquired through abjurations obtained from Einherjar.
