Myochin Armor Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

This full plate armor and the traditional mask like helmet, the kabuto, are the signs for the samurai - a legendary mercenary caste in the far eastern history. This set provides a variety of boosts to statistics and special abilities. This armor set is a tribute to the traditional Japanese Samurai.


Number of Pieces: 5
