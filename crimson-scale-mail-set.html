Crimson Scale Mail Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A full set of deep red scale armor, this set provides bonuses across the board to a variety of stats: Magic skills, MND, INT, MP, HP, ranged attacks, and even Movement Speed. This set is more of a jack-of-all-trades set than several other abjuration sets.
Like every abjuration set, this armor has a downside. In this case, the crimson set causes one to be considered a Dragon, and thus susceptible to all Dragon Killer effects, especially by Demons.
Also see the HQ version, Blood Scale Mail Set.
