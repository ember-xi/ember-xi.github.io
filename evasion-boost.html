Level 75 reference · Zenith rules

Description

Evasion Boost is a beneficial status effect that increases a mob's evasion until it wears off or is removed. Benefitting mobs gain an increase to their evasion skill (sometimes a significant increase).

How to remove the effect

  • This effect can be dispelled.
  • Some forms of Evasion Down can overwrite this effect.

How the effect is inflicted/gained

Monster Abilities

  • Antican - Sand Veil
  • Beetles - Rhino Guard
  • Rocs - Feather Barrier
  • Buffalo - Rabid Dance
  • Lizards - Secretion
  • Mamool Ja - Warm-Up
  • Tonberries - Sigh
