Setting up Ashenbubs on Ashita

From Zenith XI Wiki

Level 75 reference · Zenith rules

Ashenbubs 2x

Note: A recent Ashita update broke some plugins and addons with Ashita for Eden. All of the correct versions of Ashita and the addons/plugins are in our #tech-support channel in the pins.

Step 1: Download Ashenbubs x2 version from:  (https://www.nexusmods.com/finalfantasy11/mods/1)

Step 2: Type /aver in-game. If you're not on 3.1.1.9 then Download the correct Ashita version(3.1.1.9 When you type /aver in-game) from the Eden Discord's #tech-support channel pins and overwrite the file in your Ashita folder. If you're already on 3.1.1.9 skip to step 3

Step 3: Check inside your Ashita/plugin folder. If you already have xipivot you can skip to step 4. Download the xipivot plugin for Ashita from #tech-support pins and put it into your ashita/plugin folder (Eden Discord)

Step 4: Add /load xipivot to the top of your ashita/scripts/default.txt file. Check the example image for more detail.

File:Pivot example.png

Step 5: Put the Ashenbubs files in the ashita/plugins/DATs directory. Create the DATs folder if it doesn’t already exist

Step 6: Now load the game Type /pivot, which will load the in-game menu. Example:

File:IngamePivot.png

Step 7: Select Ashenbubs, then zone for changes to take effect.
