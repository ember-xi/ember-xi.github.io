Shadow Coat Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

This dazzling black cloth armor set provides an extreme bonus to Magic Accuracy effectively increasing one's ability to potentially land a magic spell or a song on an enemy. The Magic Accuracy bonus isn't the only bonus on this set. Small bonuses to Magic Attack Bonus, Intelligence, Mind and even Charisma are present. In addition there is a great reduction in Enmity on this armor set as well. As with every abjuration set, this set comes with the negative side-effect of greatly increasing damage taken from both physical and some magical attacks. Many players may find themselves macroing in the armor for a spell or song as with the case with the Neptunal Abjuration set.

This set has an HQ set, Valkyrie's Coat Set.
