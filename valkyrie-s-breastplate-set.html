Valkyrie's Breastplate Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

This is the HQ version of the Shadow Breastplate Set. The Valkyrie's Breastplate Set is a heavy armor set with high amounts of HP, MP, Accuracy, and Attack. The set is attainable through abjurations obtained from Einherjar.
