Level 75 reference · Zenith rules


Enhances magic defense.

Description

Spell cost: 66 MP
Ecosystem: Luminians
Type: Magical (Light)
Blue Magic Points: 3
Stat Bonus: VIT+2, AGI+2, MP+10
Jobs:

  • Blue Mage Level 72

Timers

Casting Time: 3 seconds
Recast Time: 60 seconds
Duration: 60 seconds

Combines With...

You can use Saline Coat as part of a combo to create Defense Bonus.

Can be paired with any of the following spells to create Defense Bonus combo.

  • Grand Slam
  • Terror Touch
  • Vertical Cleave

Notes

  • Self-target only.
  • Adds Magic Defense Bonus+50 which decays over time to MDB+10 before wearing off.
