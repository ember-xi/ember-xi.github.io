Baron's Saio Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

This set is a high quality version of the Trader's Saio Set. This is usually a very expensive set. A base component in the crafting of this set is Red Moko Grass. Since the grass is found through Harvesting only, its price is very high on most servers.

Number of Pieces: 5

Cost to store: Cannot be stored!
