Republic Harness Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A set of crafted armor created by fusing brass enhancements onto the Legionnaire's Harness Set. Offers all-around bonuses to many front line jobs. This is the high quality version of the Bastokan Harness Set.
