Choral Attire Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

This set with the brownish color and the typically roundlet can only be a sign for one job: the bard. All music skills are enhanced with this armor. It also provides a resist boost for wind to prevent silence. Charisma, for song effectiveness, get some points too. A set for an all-around bard. For a fee you can store the set at any Armor Storer.


Number of Pieces: 5  

Cost to store: 1000 gil
