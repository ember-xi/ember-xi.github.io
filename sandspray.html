Level 75 reference · Zenith rules


Blinds enemies within a fan-shaped area originating from the caster.

Description

Spell cost: 43 MP
Ecosystem: Beastmen
Type: Magical (Dark)
Blue Magic Points: 2
Stat Bonus: VIT+1
Jobs:

  • Blue Mage Level 66

Timers

Casting Time: 3 seconds
Recast Time: 90 seconds

Combines With...

You can use Sandspray as part of a combo to create Clear Mind.

Pair with one of the following spells to create the Clear Mind combo.

  • Poison Breath
  • Soporific
  • Venom Shell
  • Awful Eye
  • Filamented Hold
  • Maelstrom
  • Feather Tickle
  • Warm-Up
  • Lowing
  • Mind Blast

Notice, the effect stacks for each pair on this group. Each set gives MP Recovered While Healing +3.

Skillchain/Magic Burst Info

Magic Bursts on: Compression, Gravitation, and Darkness.

How to Obtain

You can learn this from the Qiqirm at Caedarva Mire, left exit of Nashmau. They con Decent Challenge to Level 73. Do not try to learn it from the Qiqirn in Aydeewa as they will run away from you.

Acquired From

Mob Family: Qiqirn
Minimum Blue Mage Level To Acquire: 58 with Magus Jubbah equipped, 60 without Magus Jubbah
