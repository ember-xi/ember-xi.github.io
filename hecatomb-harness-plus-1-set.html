Hecatomb Harness +1 Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A flexible set of bone and leather, this is the High Quality version of the Hecatomb Harness Set, adding truly large amounts of STR, DEX, and Accuracy.
Like every abjuration set, this armor has a downside. In this case, the Hecatomb +1 set has a special trait called Slow. This functions exactly opposite to pieces that say Haste. Every percent slows down melee attacks. Because of this, many players macro the Hecatomb +1 set into Weapon Skills only.
