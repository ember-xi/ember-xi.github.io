Coronach

From Zenith XI Wiki

Level 75 reference · Zenith rules

Marksmanship weapon skill

  • Skill level: N/A
  • Description: Additional effect: temporarily lowers enmity.
  • This weapon skill is only available with the stage 5 relic Gun Annihilator or within Dynamis with the stage 4 Ferdinand.
  • Lowers Enmity for a certain amount of time.

Properties

  • Element: None
  • Skillchain properties: Darkness / Fragmentation
  • Modifiers: DEX:40% ; AGI:40%
  • Damage Multipliers by TP:
100%TP 200%TP 300%TP
3.00 3.00 3.00

Notes

The amount of enmity lowered by using Coronach is very significant.
