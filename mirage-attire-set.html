Mirage Attire Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A set of armor from the Dynamis zones, which the player may be rewarded with for defeating the enemies within. Worn by Blue Mages, the Mirage set retains a similar design to their Magus Attire, but with a shift to a darker color scheme, particularly emphasizing black.

Number of Pieces: 5
