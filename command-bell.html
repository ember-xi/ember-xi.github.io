Command/bell

From Zenith XI Wiki

Level 75 reference · Zenith rules

Aliases: None
Usage: /bell [number/note]
Description:

Ring equipped bell.
You must have a bell equipped in your main
weapon slot to carry out this command.
The numbers 1-8 correspond to notes in
in an octave.
If there is no number after /bell,
the C note will be played.

Example: /bell A3+

Notes

The following notes can be specified as the parameter to the command:

File:The Version Update Is Here! (07-21-2009)-9.png
The bell can be muted using the /bellsw command.

Note: You have to have the bell sound enabled in order to hear the bells. You can enable and disable it by using the /bellsw command.

Works with any of the following weapons:

  • Dream Bell
  • Dream Bell +1
  • Lady Bell
  • Lady Bell +1

Christmas Carols

Below are several carols macro'd out with /bell C3 set as Middle C. Generally, I've treated the gap between eighth notes as <wait>, quarter notes as <wait2>, dotted quarter notes as <wait3>, half notes as <wait4>. Although I usually broke the notes between 2 macros past this point, the pattern would continue with dotted half notes as <wait5>, and whole notes as <wait6> but depending on the song, you may want to speed sections up. I will be using x to mark the wait periods I used (x means <wait>, xx means <wait2> etc.). Remember adding - makes a flat note and + makes a sharp note.
