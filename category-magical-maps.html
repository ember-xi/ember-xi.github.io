Magical Maps

From Zenith XI Wiki

Level 75 reference · Zenith rules

Magical Maps are Key Items which are obtained when you obtain a maps for a given area. Originally magical maps were permanent, but with the release of Treasures of Aht Urhgan some maps became temporary and only available upon entry and revoked upon leaving.

The following sortable table provides a list of the various magical maps and details on obtaining them. Sorting allows players to quickly find maps by different methods, such as by acquisition category (e.g. purchased, coffer, quested, mini-quest, etc), permanent versus temporary, region, etc.

The Key Item Position column should (when complete) reflect the position players find the maps listed when looking at the magical maps key items. Sorting by this column should help players determine the maps they are missing by matching the same order seen when using the menu system.
