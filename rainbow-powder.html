Rainbow Powder

Statistics

Pinch of Rainbow Powder
This fine powder diffuses light,
rendering anyone covered in it
invisible to the naked eye.

Stackable: 12

Notes:

  • Grants the user the Invisible status effect, like Prism Powder and the spell Invisible.
  • This medicine can be used while already invisible; the act of using the item will cancel the status effect, and immediately turns the user invisible again.
  • Static duration: 180 seconds (3 minutes).
