Shade Harness Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

Not merely the only set to contain pieces that have the Empty Killer trait, but every single piece has it. Wearing multiple pieces increases the Killer effect (see discussion). This trait is useful for battling all creatures of the Empty type, found in all Promyvion areas. The high quality version of this set is the Shade Harness +1 Set.
