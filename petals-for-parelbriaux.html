Walkthrough

  • Head to the 3rd floor and talk to Chemioue for a cutscene.
  • Talk to Parelbriaux at K-7 for another cutscene.
  • Now go to the 2nd floor and talk to Ondieulix for a cutscene, and the actual activation of the quest.
  • Go to Lufaise Meadows to the ??? at G-6; it needs to be selected during fog weather.
  • Fog shows up sporadically, during the morning from 1:00-7:00. It can only show when there is no weather icon up.
  • The Flytrap NM Baumesel will spawn when the ??? is selected during fog, and must be defeated.
  • If multiple people in a group need the quest, it only has to be defeated once for all of them.
  • After the NM is defeated, select the ??? again for a cutscene and to receive the Particularly Poignant Petal key item.
  • Return to the Tavnazian Safehold and talk with Ondieulix for a cutscene and to complete the quest.

Game Description

Client: Ondieulix (Main Entrance, Tavnazian Safehold)
Summary:

You have been asked to find a rare plant that is often used in medicines. It supposedly grows somewhere on the Lufaise Meadows.
