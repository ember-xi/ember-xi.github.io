Level 75 reference · Zenith rules


File:Disseverment.JPG

Delivers a fivefold attack. Additional effect: Poison. Accuracy varies with TP.

Description

Spell cost: 74 MP
Ecosystem: Luminians
Type: Physical (Piercing)
Blue Magic Points: 5
Stat Bonus: INT+1, MND-1
Jobs:

  • Blue Mage Level 72

Timers

Casting Time: 0.5 seconds
Recast Time: 32.75 seconds

Combines With...

You can use Disseverment as part of a combo to create Accuracy Bonus.

Can be paired with any of the following spells to create Accuracy Bonus combo.

  • Dimensional Death
  • Frenetic Rip

Notes

  • Piercing damage.
  • Secondary modifiers: STR: 20%, DEX: 20%.
  • Additional effect of poison is 18HP/tick.

Skillchain/Magic Burst Info

Skillchain Element(s): Distortion (can open/close Darkness with Gravitation WSs and spells)

How to Obtain

Only Thief, Bard, and Black Mage type Aerns will use this move. These Aerns always carry a dagger.

Acquired From

Mob Family: Aern
Minimum Blue Mage Level To Acquire: 63 with Magus Jubbah equipped, 66 without Magus Jubbah
