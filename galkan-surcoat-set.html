Galkan Surcoat Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A basic outfit commonly worn by the Galka, offering minimal protection. All Galka characters begin the game with this set of armor. Should you need to re-obtain these pieces, the entire set is on sale from Proud Beard at (K-8) in Bastok Mines.
