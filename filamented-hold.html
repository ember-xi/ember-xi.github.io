Level 75 reference · Zenith rules


Reduces the attack speed of enemies within a fan-shaped area originating from the caster.

Description

Spell cost: 38 MP
Ecosystem: Vermin
Type: Magical (Earth)
Blue Magic Points: 3
Stat Bonus: VIT+1
Jobs:

  • Blue Mage Level 52

Timers

Casting Time: 2 seconds
Recast Time: 20 seconds

Notes

  • Slow 25% for 120 seconds

Combines With...

You can use Filamented Hold as part of a combo to create Clear Mind.

Pair with one of the following spells to create the Clear Mind combo.

  • Poison Breath
  • Soporific
  • Venom Shell
  • Awful Eye
  • Maelstrom
  • Feather Tickle
  • Sandspray
  • Warm-Up
  • Lowing
  • Mind Blast

Notice, the effect stacks for each pair on this group. Each set gives MP Recovered While Healing +3.

Skillchain/Magic Burst Info

Magic Bursts on: Scission, Gravitation, and Darkness.
