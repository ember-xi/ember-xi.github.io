Errant Houppelande Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

The Errant Houppelande set is a high level mage set with high bonuses to MND, INT, CHR, MP,
and very high -Enmity, but has negatives to melee stats (STR, VIT, DEX, AGI, and HP)
See Mahatma Houppelande Set for high quality version.


Number of Pieces: 5 (6 with Cape)

Cost to store: Cannot be stored
