Level 75 reference · Zenith rules


Lowers Strength of enemies within a fan-shaped area originating from the caster.

Description

Spell cost: 32 MP
Ecosystem: Lizards
Type: Magical (Water)
Blue Magic Points: 2
Stat Bonus: MND+1
Jobs:

  • Blue Mage Level 46

Timers

Casting Time: 2.5 seconds
Recast Time: 60 seconds

Combines With...

You can use Awful Eye as part of a combo to create Clear Mind.

Pair with one of the following spells to create the Clear Mind combo.

  • Poison Breath
  • Soporific
  • Venom Shell
  • Filamented Hold
  • Maelstrom
  • Feather Tickle
  • Sandspray
  • Warm-Up
  • Lowing
  • Mind Blast

Notice, the effect stacks for each pair on this group. Each set gives MP Recovered While Healing +3.

Notes

  • This spell is a Gaze Attack, target must be facing your general direction for spell to take effect.
  • STR down effect starts off very high(over -30), but decays over time.

Skillchain/Magic Burst Info

Magic Bursts on: Reverberation, Distortion, and Darkness.
