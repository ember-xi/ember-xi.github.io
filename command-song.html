Command/song

From Zenith XI Wiki

Level 75 reference · Zenith rules

Aliases: /so
Usage: /song "[song name]" <target name>
Description: Uses a song on the specified target.

You cannot use a song that you have not learned, or if the current environment restricts song usage.

Notes:

  • /magic or /ma will also work to cast song spells.
  • See Macro page for more info about how to use the target name selection.
