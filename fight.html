Level 75 reference · Zenith rules

Pet Command

  • Commands your pet to attack the target.
  • Obtained: Beastmaster Level 1
  • Recast Time: 10 seconds
  • Duration: N/A

Notes/Description

A Beastmaster's level 1 Pet Command which commands his/her pet to attack a mob. The use of this Pet Command is unique in that it does not cancel Invisible.

Macro Syntax

  • /pet "Fight" <stnpc>
