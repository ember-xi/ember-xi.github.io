Mercenary Captain's Doublet Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

This set of reinforced cloth and leather armor provides warmth as well as protection. Its browns and greens give it an earthy color tone. Often mixed with damage dealing melee classes for its wide array of stat bonuses. This set is not crafted, instead requiring Conquest Points from rank 3 Windurstians. There is a crafted upgrade to this set in the form of the Windurstian Doublet Set and an HQ crafted upgrade in the form of the Federation Doublet Set.
