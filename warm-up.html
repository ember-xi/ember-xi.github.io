Level 75 reference · Zenith rules


Enhances accuracy and evasion.

Description

Spell cost: 59 MP
Ecosystem: Beastmen
Type: Magical (Earth)
Blue Magic Points: 4
Stat Bonus: VIT+1
Jobs:

  • Blue Mage Level 68

Timers

Casting Time: 7 seconds
Recast Time: 56 seconds
Duration: 180 seconds

Combines With...

You can use Warm-Up as part of a combo to create Clear Mind.

Pair with one of the following spells to create the Clear Mind combo.

  • Poison Breath
  • Soporific
  • Venom Shell
  • Awful Eye
  • Filamented Hold
  • Maelstrom
  • Feather Tickle
  • Sandspray
  • Lowing
  • Mind Blast

Notice, the effect stacks for each pair on this group. Each set gives MP Recovered While Healing +3.

Notes

  • Self-target only.
  • Adds approximately +10 Evasion and +10 Accuracy.

Skillchain/Magic Burst Info

N/A - Self Targetting spell

How to Obtain

You can only learn this from Mamool Ja fighters (THF, BST, NIN, DRG, BLU). A good place to learn is from the Mamool Ja in the Wajaom Woodlands near Mamook or just inside Mamook.
