Hunter's Attire Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

Brown and green dominates this set, with a foliaged beret for an accent. Perfect camouflage equipment for the Ranger. The armor provides a lot of job trait enhancements. For the typical weapon type - bows, crossbows and guns - there are minor boosts to agility, ranged attack and ranged accuracy. For a fee you can store the set at any Armor Storer.
