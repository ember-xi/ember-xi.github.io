Meditate

Level 75 reference · Zenith rules

Job Ability

  • Gradually charges TP.
  • Obtained: Samurai Level 30
  • Recast Time: 3:00 (Can be reduced to 2:30 using Merit Points)
  • Duration: Instantaneous (See Notes)

Notes/Description

  • When activated by a Samurai, user's TP meter will increase by 200% every two seconds for a total of ten seconds, granting the user exactly 1000% TP.
  • Using it a split second before the tic will occasionally give 1200% TP, and a split second after the tic will occasionally give only 800% TP, but this is rare.
  • When activated by a character with Samurai as a support job, user's TP meter will increase by 120% every two seconds for a total of ten seconds, granting the user 600% TP.
  • If Myochin Kabuto or Saotome Kote is equipped, when active this ability will give 200% TP every two seconds for a total of twelve or fourteen seconds, granting the user either 1200% TP or 1400% TP.
  • If both the Myochin Kabuto and the Saotome Kote the user will be granted between 1400% and 1800% TP.

Macro Syntax

  • /ja "Meditate" <me>
