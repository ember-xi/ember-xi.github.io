Centurion's Scale Mail Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

Another popular tank/DD armor set. Made of burnished steel interlocking scales, this is an impressive looking set. Bonus theme is the same as the Eisenplatte set, but wearable by more jobs, and bonuses are arranged differently. With the addition of Dexterity, this set becomes geared more toward DD characters. This set is not crafted, instead requiring Conquest Points from rank 3 Bastokans. There is a crafted upgrade to this set in the form of the Bastokan Scale Mail Set and an HQ crafted upgrade in the form of the Republic Scale Mail Set.

Number of Pieces: 5
