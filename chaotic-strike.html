Chaotic Strike

Level 75 reference · Zenith rules

Ramuh delivers a three-hit attack that also stuns target.

Technicals

Avatar: Ramuh (Lightning)

Blood Pact: Rage

Cost: 164 MP

Level: 70

Description

Effect Duration: 0-5 seconds

Battle Application: N/A

Damage Type: Blunt

Additional Notes: If all three hits land and stun processes on each one, the total effect can last up to 15 seconds. This is commonly considered the strongest stun in the game, but it will not overwrite an existing stun effect.

Macro Syntax

  • /pet "Chaotic Strike" <t>

or

  • /ja "Chaotic Strike" <t>
