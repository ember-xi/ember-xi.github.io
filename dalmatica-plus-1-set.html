Dalmatica +1 Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A luxurious set of gold gilted cloth armor. This set is the High Quality version of the Dalmatica Set, which adds significant bonuses to all mage stats: MND, INT, MP, Magic Attack Bonus, and even Refresh.
Like every abjuration set, this armor has a downside. In this case, the Zenith set gains its large MP bonus at the cost of an equal amount of HP.

Number of Pieces: 5
