Were you looking for String Instruments?


The melodies from plucked strings are able to reach even the ears of distant allies. String Instruments are good for soothing the bodies and minds of allies with a Paeon or Ballad.

  • One of the primary magic skills of the Bard. It is used when a String Instrument is equipped. Singing Skill is also taken into account when the String Instrument Skill is being used.

Note: Since String Instruments are equippable by Bards only, this skill is useless when subbed.
