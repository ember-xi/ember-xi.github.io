Level 75 reference · Zenith rules

Description

Magic Attack Boost is a beneficial status effect that increases a spellcaster's damage potential until it wears off or is removed. Benefiting characters receive an increase in magic attack, which allows their spells to hit for more damage.

How to remove the effect

  • This effect can be removed manually.
  • This effect can be dispelled.
  • This effect may be overwritten with Magic Defense Down

How the effect is inflicted/gained

Spells

  • Blue Magic - Amplification, Memento Mori

Abilities

  • Diabolos - Dream Shroud
  • Shiva - Shiva's Favor - Please Note: Needs confirmation but this looks to be out of era and will not be implemented on Eden.

Items

  • Oracle's Drink

Aftermath

  • Laevateinn
  • Murgleis
  • Tupsimati

Monster Abilities
