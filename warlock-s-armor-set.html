Warlock's Armor Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

This elegant cloth armor set is black dominated by red. Topping this set is the infamous "Pimp Hat", a red and black chapeau with a distinctive white feather. As the red mage is called jack of all trades, this set reflects this job identity and enhances a lot of spell as well as melee skills. For a fee you can store the set at any Armor Storer.


Number of Pieces: 5   Cost to store: 1000 gil   Storage marker: Warlock's Armor Claim Slip
