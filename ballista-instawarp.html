Ballista Instawarp

From Zenith XI Wiki

Level 75 reference · Zenith rules

Description
"Show this ticket to any Ballista event staff to receive a free warp back to your home point. An Instawarp can only be used once and cannot be used while participating in a Ballista match."
Notes
You will always gain an Instaport and Instawarp key item after a ballista that you take part in. Instawarp key item can be used only if the Herald is in the same battlezone.
