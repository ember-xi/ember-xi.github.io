Corsair's Attire Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

Tricorne, ornamented red frac, culottes - a perfect outfit for ship captains of the late 18th century and a well-known costume for corsairs. This set provides a major boost to ranged accuracy and most player stats. Unlike most artifact sets, it only gives one job trait enhancement (Quick Draw). For a fee you can store the set at any Armor Storer.

Number of Pieces: 5   Cost to store: 1000 gil   Storage marker: Corsair's Attire Claim Slip
