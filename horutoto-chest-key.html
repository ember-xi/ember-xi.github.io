Statistics

Horutoto Chest Key
A key that opens a treasure chest in
the Horutoto Ruins.

Type: Chest Key

Stackable: Not Stackable

Other Uses

NPC Sell Price: Cannot be sold to NPCs.

Possible Treasure

  • 450 - 900 gil
  • Amber
  • Amethyst
  • Lapis Lazuli
  • Moth Axe
  • Tourmaline

Treasure Maps

Chests on Inner Horutoto Ruins's second map Chests on Outer Horutoto Ruins's fourth map Chests on Outer Horutoto Ruins's fifth map

How to Obtain

Cannot be auctioned, traded, or bazaared, but can be delivered to a character on the same account.
