Command/heal

From Zenith XI Wiki

Level 75 reference · Zenith rules

Aliases: None
Usage: /heal [subcommand]
Description: Turns healing (kneeling) on/off.
Subcommands:
on Turn on healing.
off Turn off healing.

Toggles on and off when no subcommand is specified.

Notes

  • When using /heal the user's level is set to 0 and monsters will be aggressive towards them.

Related Commands

This is a command which has to be typed in the chat window.
