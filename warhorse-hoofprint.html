Warhorse Hoofprint

From Zenith XI Wiki

Level 75 reference · Zenith rules

Map Point Description
A hoofprint from the legendary Dark Rider.
Uses
Check to receive a Dark Rider Hoofprint (Key Item) for the quest Promotion: Superior Private.
Check to place Quartz Transmitter (Key Item) for the quest Promotion: Corporal.
Spawn Condition
Unknown. Hoofprint appears to spawn randomly, but a specific condition may cause it to spawn.
More than one hoofprint is able to be up at the same time. I was standing on 1, waiting for a friend to get it, and she found a different one within the same grid square.
