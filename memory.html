Memory

From Zenith XI Wiki

Level 75 reference · Zenith rules


This information was gathered from an Out of Era source, if you see something that is not correct for our ToAU era please contact Shoruto or update it yourself. Thanks

High level Alchemy items used for creating elemental Anima. Dropped from Empties within Promyvion - Dem, Promyvion - Holla, Promyvion - Mea, and Promyvion - Vahzl. Keep in mind that this guide pertains to "Remnants" of memories only, and not "Clusters". Clusters drop in the treasure pool after ENM battles withing the Promyvion areas.

Drop Groupings

Each empty will have three distinct drop groupings. The first is its actual elemental alignment (Fire, Water, Earth, Air, etc.). The second is its alignment to either Light (Radiant Memory) or Dark (Malevolent Memory). Fire is aligned with Light, Ice with Dark, Wind with Light, Earth with Dark, Lightning with Light and Water with Dark. The elemental alignment can be determined simply by observing the "interior" of the empty. The third grouping is designated for "Recollections" only. Recollections are unique to each individual type of empty. Each empty is capable of dropping up to two memories and one recollection.

Types of Memories

There are eight different types of memories. Each of them are represented by a different element. More than 1,000 memory drops have been monitored to verify the authenticity of the association between the type of memory being dropped with the elemental alignment of the empty that is dropping it. As you can see from the chart below, there are two core types of elements, Light and Dark.

What type of Memory will drop?

  • Burning Memory - Will drop from Fire empty only!
  • Somber Memory - Will drop from Ice empty only! (Yes, Water memories drop from Ice empty.)
  • Fleeting Memory - Will drop from Wind empty only!
  • Profane Memory - Will drop from Earth empty only!
  • Startling Memory - Will drop from Lightning empty only!
  • Bitter Memory - Will drop from Water empty only! (Yes, Ice memories drop from Water empty.)
  • Malevolent Memory - Will drop from Dark empty, and from any empty associated with the Darkness (Skillchain). (Dark element empty can drop up to two malevolent memories. One in each of the first two drop groupings mentioned above.)
  • Radiant Memory-Will drop from Light empty, and from any empty associated with the Light (Skillchain). (Light element empty can drop up to two radiant memories. One in each of the first two drop groupings mentioned above.)

WITH THE EXCEPTION OF DARK AND LIGHT ELEMENT EMPTY, THERE IS NO ASSOCIATION BETWEEN SKILLCHAINS AND THE TYPE OF MEMORY THAT CAN DROP!!!

WITH THE EXCEPTION OF MALEVOLENT (DARK) AND RADIANT (LIGHT) MEMORIES, EACH MEMORY IS UNIQUE TO ONE ELEMENTAL TYPE AND CANNOT BE DROPPED FROM AN EMPTY ASSOCIATED WITH ANOTHER ELEMENT!!!
