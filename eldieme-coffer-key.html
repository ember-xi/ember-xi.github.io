Statistics

Eldieme coffer key
A key that opens a treasure coffer in
the Eldieme Necropolis.

Type: Coffer Key

Stackable: Not Stackable

Other Uses

Used in Quests:

  • Borghertz's Shadowy Hands
  • Borghertz's Stalwart Hands
  • Borghertz's Vermillion Hands
  • Borghertz's Warring Hands


NPC Sell Price: Cannot be sold to NPCs.

Possible Treasure

  • 7,370 - 10,340 gil
  • Old Gauntlets (DRK, RDM, WAR, PLD)*
  • Wizard's Tonban*
  • Vile Elixir +1
  • Chrysoberyl
  • Fluorite
  • Moonstone
  • Sunstone

* Only available if you have the necessary quest active.

Treasure Maps

Use the route map to move between floors. Numbered pins on Map 2 mark the five possible coffer locations shown on the cited Horizon treasure map; they do not show the coffer's current live position.

Map 3 — Connecting route · HorizonXI treasure-map reference

How to Obtain

Cannot be auctioned, traded, or bazaared, but can be delivered to a character on the same account.
