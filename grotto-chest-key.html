Grotto Chest Key

Statistics

Grotto chest key
A key that opens a treasure chest in
the Sea Serpent Grotto.

Type: Chest Key

Stackable: Not Stackable

Other Uses

Used in Quests: A Test of True Love

NPC Sell Price: Cannot be sold to NPCs

Possible Treasure

  • 3,520 - 6,400 gil
  • Garnet
  • Goshenite
  • L'Ephemere*
  • Map of the Sea Serpent Grotto**
  • Onyx
  • Peridot
  • Turquoise

* Only available if you have the necessary quest active.
** Automatically received if you do not already have the map. Quest items take priority.

Treasure Maps

Chests on Sea Serpent Grotto's first map Chests on Sea Serpent Grotto's second map

How to Obtain

Cannot be auctioned, traded, or bazaared, but can be delivered to a character on the same account.
