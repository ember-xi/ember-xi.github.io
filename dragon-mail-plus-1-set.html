Dragon Mail +1 Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A high-quality set of armor smithed exclusively for Dragoons, the Dragon Mail set represents a powerful defense against any magic or breath using mob - with the full set, the user is granted +24 resistance to all elements (including light and dark elements), and only takes 70% damage from breath attacks. The normal quality version of this set is the Dragon Mail Set.
