Walkthrough

Note: You can not start this quest immediately after completing Chocobilious. It has been reported that some time must pass before you do so. As with other quests, you must change areas after completing Chocobilious before starting this quest.

  • Talk to Kuoh Rhel to learn that she needs to mask the Chocobo medicine in delicious soup.
  • Talk to Matata who's right next to Kuoh Rhel (K-12).
  • Now go to Windurst Waters and talk to Ranpi-Monpi in the Cooking Guild (D-9). Then trade him the 3 Woozyshrooms that he wants (if you have A Crisis in the Making active, he will only talk about that quest, but just trade him the items anyways and it will still work).
  • Return to Kuoh Rhel to complete this quest.

Game Description

Client: Kuoh Rhel (Chocobo Stables, Windurst Woods)
Summary:

Kuoh tried to feed the sick Chocobo some "secret cure-all medicament," but it wouldn't swallow it. She wants to try and hide the taste by mixing it in some of the bird's favorite food, if you can help obtain some...
