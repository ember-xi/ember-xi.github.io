Ninja's Garb Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

Ninjas are practicing the martial arts of the far-east. Stealth, speed and the art of hitting with dualwielding katanas and throwing shuriken - these statistics are enhanced with this set. The entire black coloured set fits perfectly for ninjas. For a fee you can store the set at any Armor Storer. For the +1 version, see Ninja's Garb +1 Set.
