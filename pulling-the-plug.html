Notes

  • Venessa in Ru'Lude Gardens (H-10) will offer you the option into Promyvion - Vahzl if you have completed the Chains of Promathia missions and reached chapter 5 or above.
  • If you select the 'Spire of Vahzl' she will give you the Censer of Acrimony key item.
  • Upon entering the Spire of Vahzl, you will have the option of entering the ENM battle at the battlefield.
  • To win this ENM, only Memory Receptacle (Red) must be defeated.
  • Memory Receptacle (Red) is the only NM at the start. When it is approached, the other three colored Memory Receptacle NMs spawn. One of the three Memory Receptacles has to be defeated before any damage can be done to Memory Receptacle (Red). They appear either in 3 of the 4 corners of the room or in a row next to Memory Receptacle (Red), and periodically rotate to the next corner or to a different side of Memory Receptacle (Red).
    • When Memory Receptacle (Teal) is defeated, Contemplator spawnsVerification Needed.
      • Killing Memory Receptacle (Teal) makes Memory Receptacle (Red) vulnerable to melee damage.
    • When Memory Receptacle (Green) is defeated, Ingurgitator and Neoingurgitator spawnVerification Needed.
      • The Neoingurgitator disappears when the Ingurgitator is defeated.
      • Killing Memory Receptacle (Green) makes Memory Receptacle (Red) vulnerable to magic damage.
    • When Memory Receptacle (Blue) is defeated, the Repiner spawnsVerification Needed.
      • Killing Memory Receptacle (Blue) makes Memory Receptacle (Red) vulnerable to ranged damage.
  • The Contemplator, Ingurgitator, Neoingurgitator, and Repiner are vulnerable to the effects of Psychoanima and Hysteroanima, and may be vulnerable to Terroanima Verification Needed. They do not need to be killed to win the ENM or to remove the damage resistances of Memory Receptacle (Red).
  • All Memory Receptacles use Empty Seed.
  • Memory Receptacle (Red) draws a random player into the center about every 20 seconds.

Note: When a Memory Receptacle is defeated, the NM it spawns seems to vary depending on where in the battle field the MR was when it was defeated. The above info states that each MR spawns a particular NM, this is not true. We defeated the Blue MR this evening, and the Repiner spawned in its place.
