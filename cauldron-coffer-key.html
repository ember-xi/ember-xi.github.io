Statistics

Cauldron coffer key
A key that opens a treasure coffer in
the Ifrit's Cauldron area.

Type: Coffer Key

Stackable: Not Stackable

Other Uses

Used in Quests: Borghertz's Lurking Hands

NPC Sell Price: Cannot be sold to NPCs.

Possible Treasure

Note: This list is missing normal rewards.

  • ~13,600 gil
  • Drachen Mail*
  • Map of Ifrit's Cauldron**
  • Old Gauntlets (NIN)*

* Only available if you have the necessary quest active.
** Automatically received if you do not already have the map. Quest items take priority.

Treasure Maps

Coffers on Ifrit's Cauldron's first map Coffers on Ifrit's Cauldron's second map Coffers on Ifrit's Cauldron's fourth map Coffers on Ifrit's Cauldron's seventh map

How to Obtain

Cannot be auctioned, traded, or bazaared, but can be delivered to a character on the same account.
