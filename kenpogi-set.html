Kenpogi Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A basic set of cloth armor, usable by the Far East jobs, the Kenpogi offers Monks, Samurais, and Ninjas the opportunity to forgo the typical low-level options and instead use a more traditional armor. However, like almost all of the low-level armor sets, the Kenpogi set only adds to the defense of the wearer. The high quality version of this set is the Kenpogi +1 Set.
