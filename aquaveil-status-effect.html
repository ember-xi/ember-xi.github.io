Level 75 reference · Zenith rules

Description

Aquaveil is a beneficial status effect that calms the mind and allows for greater focus until it wears off or is removed. Benefitting characters receive a reduction in Spell Interruption Rate, equivalent to -25%.

How to remove the effect

  • This effect can be dispelled.
  • This effect can be removed manually.
