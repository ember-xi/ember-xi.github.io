Command/throw

From Zenith XI Wiki

Level 75 reference · Zenith rules

Aliases: /range, /ra, /shoot
Usage: /throw "[target name]"
Description: Uses range attack on specified target.
Example: /throw "Goblin Smithy"

Notes

The in-game help does not make mention of this command's use in Ballista or Brenner. If anyone has knowledge of its use, please edit this page with the relevant information.
