Plastron Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

This crafted armor set is wearable only by Dark Knights level 71 and over. It adds a large boost attack but at a very costly penalty in the increase of damage taken. Also the only armor set/pieces that enhance absorb spells.
See Plastron +1 Set for the high quality version.

Number of Pieces: 5

Cost to store: Cannot be stored.
