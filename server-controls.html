Server Controls

From Zenith XI Wiki

Manage the four server processes from the launcher.

Start and restart

ControlBehavior
Start server / Stop serverThe label follows the verified process state.
Restart MapRestart the map process only.
Restart allRestart all four server processes.
Show consoles / Hide consolesToggle only the four server consoles. The label follows their visibility.

Exit the game before stopping or restarting the server. Lua changes may need a restart depending on where they load; C++ changes need a build. Database changes must be applied before the relevant server startup.

Status indicator

ColorMeaning
GreenProcess is running.
RedProcess is stopped.
AmberState could not be verified.

A running process alone does not prove the server is ready for login. The Ashita/xiloader console is independent and handled by its addon; it does not open with Show consoles.

Login and shortcuts

Remember me encrypts saved login details under the Windows user account. The Start Menu shortcut supports pinning the launcher to the taskbar.

Troubleshooting scope

Client/server compatibility issues, incorrect loot text and addon faults are separate from console visibility. Hiding a window does not resolve CastBar or Equipmon errors. Those fixes are not claimed by this launcher package.
