Seer's Tunic Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

An elegant mage armor set of black cloth embroidered with decorative gold, the Seer's set is perfect for a mage looking to reinforce their skills with the magic-oriented stat bonuses that the Seer's set provides. The Seer's is one of the most solid and reliable mage armor sets until many mages' artifact armors, and even then, some mages keep and use parts of their Seer's set well beyond the artifact levels. The high quality version of this set is the Seer's Tunic +1 Set.
