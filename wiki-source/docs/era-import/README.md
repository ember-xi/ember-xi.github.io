# Level-75 reference import — 26 September 2026

The build consumes the self-contained snapshots in `content/era-reference`.
Run `python tools/build-wiki.py`, then `check-wiki.py`, `check-era-reference.py`,
`check-missions.py`, and `check-zones.py` from `tools/`.

Eden Wiki text is adapted under CC BY-SA 4.0. Every source article retains its
revision, source URL, contributor-history link and license notice. Text is
reformatted, linked locally, and optional historical/etymological sections are
omitted. Game images have separate source attribution; game artwork remains
copyright SQUARE ENIX. Horizon imagery is used with individual file references;
Horizon prose is not bulk copied.

`inventory.json` records the complete source scope, exclusions and replacements.
Source administration, player rosters, installation instructions and source-only
seasonal announcements are excluded. An upstream cooldown interrupted the last
84 source pages: 80 received independently written guides, three were already
covered by existing Zenith area guides, and one duplicate encounter-video page
was excluded. No source restrictions were bypassed.

Dancer, Scholar and missing progression dependencies have original concise
supplements with sources. Original era requirements are distinguished from
later retail changes and source-server custom rules. These are reference pages,
not evidence that every encounter or package is installed on the live server.
Existing Zenith availability notes and mission requirements remain authoritative.

`recipe-scope.json` records later-expansion recipes removed from the native item
reference. The renderer also removes the two post-era jobs from imported
eligibility lists. Source/route coverage, distinct similarly named quests/items,
all 20 jobs, AF/Relic references, supplemental links and existing mission/zone
content are checked before publication.
