Display Settings

From Zenith XI Wiki

Configure game rendering and interface size separately in Settings → Display.

Contents
  1. Display options
  2. Apply changes
  3. Launcher size

Display options

SettingPurpose
Windowed / Fullscreen / BorderlessSelect a window, full screen or a borderless window. All three resolutions remain editable in Borderless.
MainThe game window size. Use desktop size changes only this resolution.
BackgroundThe 3D world rendering resolution.
UIThe resolution of the menu and text workspace.
Game UI ScaleOptions such as 100%, 125%, 150%, 175% and 200%, depending on resolution. At Main 1920×1080 and 150%, UI becomes 1280×720; Background is unchanged.

Apply changes

Save and restart the game. Some addon interfaces have their own scaling settings.

Launcher size

Settings → Launcher provides 75%, 85%, 100% and 115% launcher scaling. Save and reopen the launcher. The pointer follows the Windows cursor size.
