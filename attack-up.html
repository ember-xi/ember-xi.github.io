Level 75 reference · Zenith rules

Description

Attack Up is a beneficial status effect that boosts the player's attack until it wears off or is removed. Benefitting characters have a temporary increase to their attack.

How to remove the effect

  • This effect can be dispelled.
  • This effect can be removed manually.

How the effect is gained

Monster Abilities

  • Scorpions - Sharp Strike
  • Coeurls - Frenzied Rage
