Ranged Accuracy

From Zenith XI Wiki

Level 75 reference · Zenith rules

Determines the accuracy of Ranged Attack. Adding 2 points to a character's AGI will increase this stat by one point.
Total ranged accuracy calculation is assumed to be the same as that of melee accuracy.
Formula:

  • When combat skill is <=200
Ranged Accuracy = ( Combat Skill + AGI/2 + (+Ranged accuracy from gear) + (+Ranged accuracy from trait/ability) ) * (1+ percentage from food effect)
  • When combat skill is beyond 200
Ranged Accuracy = ( 200+ (Combat Skill-200)*0.92 + AGI/2 + (+Ranged accuracy from gear) + (+Ranged accuracy from trait/ability) ) * (1+ percentage from food effect)
