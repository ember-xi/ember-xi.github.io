Level 75 reference · Zenith rules

Description

File:Regen (Status Effect).png Regen is a beneficial status effect that refreshes a player's hit point pool until it wears off or is removed. Benefitting characters gain hit points back while standing or sitting.

How to remove the effect

  • This effect can be dispelled.
  • This effect can be removed manually.

How the effect is inflicted/gained
