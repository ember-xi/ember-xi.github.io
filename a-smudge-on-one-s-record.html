Walkthrough

  • Bring Hariga-Origa a Slime Oil, which drops from various slime creatures, and a frost turnip, which can be bought on the Auction House or the Valdeaunia regional merchant.

Game Description

Client: Hariga-Origa (Optistery, Windurst Waters)
Summary:

While transcribing an ancient manuscript, Hariga-Origa finds a smudge that makes the writing unreadable. He wants you to help find an item that will clear the nasty blot away.
