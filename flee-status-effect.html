Flee (Status Effect)

From Zenith XI Wiki

Level 75 reference · Zenith rules

Description

Flee is a beneficial status effect that enables a character to run like a chocobo until it wears off or is removed. Benefiting characters receive an improvement to their movement speed.

How to remove the effect

  • A monster casting Dispel or Magic Finale can remove this effect.
  • This effect can be removed manually
  • Certain types of Weight can overwrite Flee (Status Effect)

How the effect is gained

Items

  • Hermes Quencher
  • Powder Boots
  • Caitiff's Socks
  • Chicken Knife
  • Sprinter's Drink

Environmental Effect

  • Possible random effect gained from the swamps in Caedarva Mire

Job Abilities

  • Thief - Flee
