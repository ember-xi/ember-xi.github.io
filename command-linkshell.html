Command/linkshell

From Zenith XI Wiki

Level 75 reference · Zenith rules

Aliases: /l
Usage: /linkshell [message]
Adjusting Chat Mode

/chatmode linkshell
/cm l

Description:

Sends a message to all linkshell members.
In order to receive a /linkshell message, the player has to be online and not currently changing zones.

Example: /linkshell So what do we want to do tonight?
