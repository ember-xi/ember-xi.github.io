Command/bank

From Zenith XI Wiki

Level 75 reference · Zenith rules

Aliases: None
Usage: /bank
Description: Opens the Mog Safe menu.
Example: /bank

Notes

You can use this command anywhere to view the contents of your Mog Safe.
If you use this command inside a Mog House, then you will also be able to move items between your Inventory and Mog Safe.
