San d'Orian Vest Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A set of crafted armor created by adding extra sheep leather onto the Royal Footman's Vest Set. Offers all-around bonuses to many front line jobs. The high quality version of this set is the Kingdom Vest Set.
