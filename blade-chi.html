Level 75 reference · Zenith rules


Katana weapon skill

  • Skill level: 150
  • Delivers a two-hit earth elemental attack.

Properties

  • Element: Earth
  • Skillchain properties: Impaction/Transfixion
  • Modifiers: STR:30% ; INT:30%
  • Damage Multipliers by TP:
100%TP 200%TP 300%TP
Unknown Unknown Unknown

Translation

This particular character of "Chi" means earth. So it is Blade: Earth.

Notes

Definitely one of the best weapon skills till Blade: Jin. When using it during EXP Party, bring along some INT+ gear to equip in a macro for the WS. Great for holding hate.
