Shura Togi Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A sturdy set of wood paneled armor which allows for free range of movement, for practitioners of the eastern martial arts. The Shura set adds significant bonuses to STR, Attack, and Accuracy.
Like every abjuration set, this armor has a downside. In this case, the Shura set has moderately low Defense for its level, and each piece has a negative HP modifier.
Also see the HQ version, Shura Togi +1 Set.
