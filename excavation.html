Excavation

From Zenith XI Wiki

Level 75 reference · Zenith rules

Hobby in which various items can be harvested by using a pickaxe at an Excavation Point. In order to excavate, all you need to do is use your pickaxe in the item list on the Excavation Point. You can set the following macro in order to speed up the process:

/item Pickaxe <t>

Pickaxes can break with use. Excavation points are located in the following zones...

  • Some locations are missing because it is not known what can be excavated.
