Puppetry Attire +1 Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

The High Quality version of the Puppetry Attire Set, enhancing the both the Puppetmaster and the Automaton through various pieces of colorful and showy clothing. Crafted with only the finest velvet, scarlet, and silk, this set has an unearthly sheen to it. Far surpassing the original work received from Dhima Polevhia, Sagheera's craftsmen have indeed rejuvenated and given new life to this set of equipment.
