Beast Armor Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A hume male in full Beast Armor]] This entire set is created in the style of an white sheep skin and who else should use it: Yes, the beastmaster. This armor enhances the job abilities "Tame" and "Reward" and improves the "Killer" traits. It provides an incredible boost for "Charm" plus a slight bonus for charisma, too. With this set your pet will be your friend for sure. For a fee you can store the set at any Armor Storer.
