Level 75 reference · Zenith rules

Description

Magic Defense Boost is a beneficial status effect that increases a character's magic defense until it wears off or is removed. Benefitting characters receive an increase in magic defense, which reduces the damage caused by spells cast on them.

How to remove the effect

  • This effect can be removed manually.
  • This effect can be dispelled.

How the effect is inflicted/gained

Spells

  • Blue Magic - Saline Coat

Blood Pacts

  • Diabolos - Dream Shroud

Monster Abilities

  • Nightmare Crab - Enhanced version of Bubble Curtain
