Level 75 reference · Zenith rules

Description

Accuracy Down is a harmful status effect that disorients players until it wears off or is removed. Afflicted characters have reduced accuracy.

How to remove the effect

  • The White Magic spell Erase will remove this effect

How the effect is inflicted/gained

Spells

  • Blue Magic - Sandspin

Weapon Skills

  • Full Break

Monster Abilities

  • Adamantoise - Head Butt
  • Worm - Sandspin
  • Bat Trios - Slipstream
  • Tonberries - Vertical Slash
  • Fomors - Barbed Crescent
