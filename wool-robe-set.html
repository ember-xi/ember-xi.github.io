Wool Robe Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

Standard cloth armor templates make this a familiar armor set, just a different color. While generally not a popular set, due to a lack of additional bonuses, this set is still useful in the fact that it is comparably cheap. All pieces can be bought off a merchant in Lower Jeuno. The high quality version of this set is the Wool Robe +1 Set.
