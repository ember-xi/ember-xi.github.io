Reduces an enemy's TP.

Description

Spell cost: 48
Ecosystem: Birds
Type: Magical (Wind)
Blue Magic Points: 3
Stat Bonus: AGI+1
Jobs:

  • Blue Mage Level 64

Timers

Casting Time: 4 seconds
Recast Time: 26 seconds

Combines With...

You can use Feather Tickle as part of a combo to create Clear Mind.

Pair with one of the following spells to create the Clear Mind combo.

  • Poison Breath
  • Soporific
  • Venom Shell
  • Awful Eye
  • Filamented Hold
  • Maelstrom
  • Sandspray
  • Warm-Up
  • Lowing
  • Mind Blast

Notice, the effect stacks for each pair on this group. Each set gives MP Recovered While Healing +3.
