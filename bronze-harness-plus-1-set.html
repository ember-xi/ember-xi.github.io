Bronze Harness +1 Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A very common set of armor for most fighter and rogue type jobs. The bronze plating of the Bronze Armor Set provide support to muscles, bones, and joints of an adventurer whilst protecting vital areas from attacks, all the while doing very little to limit movement of the wearer. This is the high quality version of the Bronze Harness Set.
