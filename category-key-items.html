Key Items

From Zenith XI Wiki

Level 75 reference · Zenith rules

Key Items are items that are obtained but are not "usable" like other normal items. A key item can be used to enter certain areas, advance farther in quests, etc. You can view all of your key items from the main menu. Each Key Item can be clicked on for a description. Common Key Items are maps, airship passses, and some quest items. Key Items are stored separately from your Inventory, and there is no limit to the amount of Key Items you may have.

Key Items are sorted into the following categories:

  • Temporary Key Items (e.g. Assault Orders)
  • Permanent Key Items (e.g. Airship Pass)
  • Magical Maps (e.g. Map of the San d'Oria Area)
  • Claim Slips (e.g. Warlock's armor claim slip)
  • Active Effects (e.g. Moghancements)
