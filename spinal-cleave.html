Description

Spell cost: 61 MP
Ecosystem: Undead

Stat Bonus: VIT+2, INT+1, MND+1
Jobs:

  • Blue Mage Level 63

Timers

Casting Time: 0.5 seconds
Recast Time: 28.5 seconds

Combines With...

You can use Spinal Cleave as part of a combo to create Attack Bonus.

Can be paired with any of the following spells to create Attack Bonus combo.

  • Battle Dance
  • Uppercut
  • Death Scissors
  • Temporal Shift

Notes

  • Slashing damage.
  • Secondary modifiers: STR: 30%.
  • Ignores shadows.

Skillchain/Magic Burst Info

Skillchain Element(s): Earth/Wind (can open Scission, Reverberation, Detonation, Gravitation, or Liquefaction; can close Scission or Distortion, Detonation)

How to Obtain

You must first break the Qutrub's right hand weapon. It will only use the skill while it no longer has a weapon. If you break its second weapon, it will no longer use Spinal Cleave, however occasionally it will put it's weapon away and continue to fight using H2H.
