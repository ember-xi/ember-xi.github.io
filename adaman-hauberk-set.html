Adaman Hauberk Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A shiny blue metal set of armor. The Adaman set adds signifigant bonuses to STR, DEX, Attack, and Accuracy for strong melee damage.
Like every abjuration set, this armor has a downside. In this case, the Adaman set gains its offensive melee bonuses at the expense of an array of defensive and mage stats. HP, MP, INT, MND, Evasion, and Vitality are sacrificed.
Also see the HQ version, Armada Hauberk Set.
