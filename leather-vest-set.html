Leather Vest Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A simple set of light armor made almost entirely from Sheep Leather, with other very basic components. Offers defense bonuses for light melee jobs. The high quality version of this set is the Leather Vest +1 Set.
