Walkthrough

  • Accept the quest and get the key item Note From Hariga-Origa.
  • Go speak with Ipupu in West Sarutabaruta, in the tower between I-8 and J-8.
  • If you exit to West Sarutabaruta from Windurst Waters, the tower is right next to the exit.
  • Ipupu will give you the key item Note From Ipupu.
  • Return to Hariga-Origa to complete the quest.

Game Description

Client: Hariga-Origa (Optistery, Windurst Waters)
Summary:

While transcribing an ancient manuscript. Hariga-Origa chanced upon a glyph that he cannot read. He wants you to track down Ipupu, a specialist in paleography, and hand her a note that contains the unknown letter.
