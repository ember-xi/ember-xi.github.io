Design references

World Quests source review

NPC routing, objective checks and reward ownership are checked against world_npcs.lua, quest_trials.lua and the modified quest providers. Positions come from reviewed NPC data or script coordinates; map squares are checked against the game-map grid.

Game-map locations

NPCs, quest markers and training books use map squares. The labels are derived from the installed positions and checked with VanaCompass grid calibrations and FFXIDB map transforms. Dungeon map geometry was reviewed for Boyahda, Crawlers’ Nest, Garlaige and Eldieme. Custom marker locations follow Zenith’s files.

Adventures v1.1

Native spawn IDs, levels, loot and positions were read from the pinned LandSandBoat source snapshot f45ab5c0aa3607b4b8fb694da58434e4dd29a2e4. Gear uses native equipment/job masks and the existing 689-item Zenith market catalogue; 448 equipment records are included. Quest reminders were checked against original Jeuno quest scripts. Native-data hashes and offline test results accompany the installer. Inventory uses the native getContainerSize/changeContainerSize API and a positive delta only. Reward IDs, quantities, equipment levels and displayed stats were checked against native item SQL. Map grid references are linked beside each route; highlights identify cells, not an inferred coordinate conversion.
