Elder Armor Set (Galka)

From Zenith XI Wiki

Level 75 reference · Zenith rules

The cut of this armor set is identical to the level 1 RSE gear every Galka gets for free on a new character. The main difference is that instead of red, the color scheme for this set is a stunning eye-catching blue and the tail is more decorated on the Braguette. The RSE set makes up for the natural racial weaknesses, which in the case of Galka are MP, INT, CHR, and AGI.
