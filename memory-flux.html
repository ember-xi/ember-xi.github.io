Memory Flux

From Zenith XI Wiki

Level 75 reference · Zenith rules


Memory Fluxes appear in all the Promyvions. They appear to be gateways which allow adventurers to skip previously conquered floors in the Promyvions when they come back at a later time.

  • However, they do not appear to work in Promyvion - Dem, Promyvion - Holla or Promyvion - Mea.
  • In Promyvion - Vahzl, on levels three, four, and five, you will have to search for Memory Flux gates to spawn NMs before you may advance to the next floor. These are mandatory fights and required to proceed with the mission.
    1. The one on the third floor is a Propagator (Gorger type)
    2. The one on the fourth floor, a Solicitor (Craver type)
    3. The one on the fifth floor, a Ponderer (Thinker type)
  • After defeating each NM in Promyvion - Vahzl, checking the Memory Flux sets your memory to that point which will allow you to quickly return to that point at a later date.
