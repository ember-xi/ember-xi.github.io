Legionnaire's Harness Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A set of armor with the same appearance as the Bronze Harness Set. This set, however, originates from Bastok, requiring Conquest Points from rank 1 and 2 Bastokans. It is equippable by most common front line jobs and offers small bonuses to vitality, intelligence, attack, and various elements in addition to its defense. There is a crafted upgrade to this set in the form of the Bastokan Harness Set and an HQ crafted upgrade in the form of the Republic Harness Set.
