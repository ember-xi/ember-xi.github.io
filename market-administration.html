Market Administration

From Zenith XI Wiki

Install and manage Auction Market v1.0 from its package tools.

Contents
  1. Installation
  2. Operation
  3. Commands
Status: Installation record found in the 19 September audit; automatic stocking and live operation are not yet verified. Details

Installation

  1. Exit the game and stop the server from the launcher.
  2. Extract ZenithXI-Auction-Market-v1.0.zip and run Install.cmd.
  3. Wait for INSTALLED, then start Zenith. No server rebuild is needed.

Operation

The scheduled service runs every five minutes and at Windows sign-in. MariaDB must be available and a Windows user signed in. It does not require a visible console.

Commands

ToolPurpose
Status.cmdShow service status.
Pause.cmdPause automation.
Resume.cmdResume automation.
Refresh.cmdRun a cycle now.
Remove.cmdAfter stopping the server, withdraw unsold system listings and restore the search setting. Player listings, completed sales and received gil remain.

The package passed 24 local MariaDB integration checks, including delivery, duplicate-spending prevention and interrupted-operation rollback. Its Windows scheduled task and in-game operation have not yet been confirmed.
