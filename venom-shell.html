Level 75 reference · Zenith rules


Poisons enemies within range and gradually reduces their HP.

Description

Spell cost: 86 MP
Ecosystem: Aquans
Type: Magical (Water)
Blue Magic Points: 3
Stat Bonus: MND+2
Jobs:

  • Blue Mage Level 42

Timers

Casting Time: 3 seconds
Recast Time: 45 seconds

Combines With...

You can use Venom Shell as part of a combo to create Clear Mind.

Pair with one of the following spells to create the Clear Mind combo.

  • Poison Breath
  • Soporific
  • Awful Eye
  • Filamented Hold
  • Maelstrom
  • Feather Tickle
  • Sandspray
  • Warm-Up
  • Lowing
  • Mind Blast

Note: The effect stacks for each pair on this group. Each set gives MP Recovered While Healing +3.

Skillchain/Magic Burst Info

Magic Bursts on: Reverberation, Distortion, and Darkness.

How to Obtain

Acquired From

Mob Family: Uragnite
Minimum Blue Mage Level To Acquire: 32
Name Level Zone
Uragnite 30-37 Manaclipper
Coralline Uragnite 32-35 Bibiki Bay - Purgonorgo Isle

Note: Due to the monster's defense, it is suggested you have additional help in order to be able to defeat the monster. Also they use the poison abilities often, so either have a WHM with Poisona or bring along (quite a few) stacks of Antidote.
