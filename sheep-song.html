Level 75 reference · Zenith rules

Puts all enemies within range to sleep.

Description

Spell cost: 22 MP
Ecosystem: Beasts
Type: Magical (Light)
Blue Magic Points: 2
Stat Bonus: CHR+1, HP+5
Jobs:

  • Blue Mage Level 16

Timers

Casting Time: 3 seconds
Recast Time: 60 seconds

Combines With...

You can use Sheep Song as part of a combo to create Auto Regen.

Can be paired with the following spell to create Auto Regen combo.

  • Healing Breeze

Notes

  • Area of effect is centered around caster.

Skillchain/Magic Burst Info

Magic Bursts on: Transfixion, Fusion, and Light.
