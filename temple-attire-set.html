Temple Attire Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

This brown and black colored set is created for monks. The game designer did not focus on any single statistic, so every piece of armor but the legs enhances one statistic and one of the monk's Job Abilities. The entire set balances out the monk's martial-arts fighting style. For a fee you can store the set at any Armor Storer.
