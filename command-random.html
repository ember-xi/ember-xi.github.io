Command/random

From Zenith XI Wiki

Level 75 reference · Zenith rules

Aliases: None
Usage: /random
Description: Displays a random number between 0 and 999, inclusive. This number can be seen by PCs within the Say radius.
Example: Dice Roll! <Name> rolls <random number>!

Notes

Currently there is no filter for this event.
Using the /blacklist command on a specific player can stop unwanted randoms.
