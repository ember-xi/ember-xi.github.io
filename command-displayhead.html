Command/displayhead

From Zenith XI Wiki

Level 75 reference · Zenith rules

Aliases: none
Usage: /displayhead [on/off]
Description:

Turns display mode for head gear on or off. If it is turned on (default) the current head gear of the character will be visible for all other characters and itself. The argument of the command is case sensitive. This means it must be written in small letters to actually work.

Example: /displayhead off
