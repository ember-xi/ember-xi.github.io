Gilt Cuirass Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A set of plate armor with the same appearance as the Iron Musketeers' custom armor. This set is crafted largely of gold and cermet, and offers high defense, vitality bonuses, and dark resistance. This is the HQ version of the Gold Cuirass Set.
