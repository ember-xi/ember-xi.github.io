Community Service

From Zenith XI Wiki

Level 75 reference · Zenith rules

  Start NPC:   Zauko - Lower Jeuno (I-6)
  Requirements:
   Jeuno Reputation 1
  Items Needed:   None.
  Title:   Torchbearer
  Repeatable:   Yes
  Reward:   Jeuno Fame, Lamp Lighter's Membership Card (if repeated)

  Previous Quest:   None
  Next Quest:   None

Walkthrough

  • Talk to Zauko between 18:00 and 21:00
  • Zauko needs you to light all the lamps before 1:00.
  • There are 12 lamps along the entire length of Lower Jeuno.
  • Click on each one to light it, then return to Zauko after you've lit all twelve.
  • Assuming no lag, it takes around 2 game hours to walk to each lamp and light it, so plan accordingly.

Game Description

Client: Zauko (Lower Jeuno)
Summary:

Zauko needs someone to help light the streetlamps

Note

If no one accepts Zauko's quest before 1:00 game time, Vhana Ehgaklywha appears to light the streetlamps.
This quest can be offered to only one person in one day of Vana'Diel time on each server.

If this quest is repeated Zauko will offer you a Lamp Lighter's Membership Card which will notify you if the Community Service Quest is open whenever you enter Lower Jeuno.
