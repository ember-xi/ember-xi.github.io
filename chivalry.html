Level 75 reference · Zenith rules

Job Ability

  • Converts TP to MP.
  • Obtained: Paladin Level 75 (Must be Purchased with Merits)
  • Recast Time: 20:00
  • Duration: Instant

Notes/Description

  • This Job Ability can only be learned by using Merit Points.
  • Initially, the recast timer is at 20:00. Every Merit Point upgrade will reduce the recast timer by 2:30.
  • MP recovered = current TP * (0.5 + MND*0.015)
  • Initially reported to give a very large boost to enmity when used... now found to be untrue. Only gives you back alot if not all of your MP.

Macro Syntax

  • /ja "Chivalry" <me>
