Level 75 reference · Zenith rules


Gives enemies within range a powerful disease that prevents recovery of HP and MP.

Description

Spell cost: 66 MP
Ecosystem: Beasts
Type: Magical (Fire)
Blue Magic Points: 2
Stat Bonus: HP-5
Jobs:

  • Blue Mage Level 71

Timers

Casting Time: 7 seconds
Recast Time: 56 seconds

Notes

The effect inflicted by this spell is Plague (For which the help text says "You are affected by a powerful disease.").

Need Confirmation: Drains MP by 3 per tick.

Tested with /bst : Drains TP by 5 tick.

Combines With...

You can use Lowing as part of a combo to create Clear Mind.

Pair with one of the following spells to create the Clear Mind combo.

  • Poison Breath
  • Soporific
  • Venom Shell
  • Awful Eye
  • Filamented Hold
  • Maelstrom
  • Feather Tickle
  • Sandspray
  • Warm-Up
  • Mind Blast

Notice, the effect stacks for each pair on this group. Each set gives MP Recovered While Healing +3.

Skillchain/Magic Burst Info

Magic Bursts on: Liquefaction, Fusion, and Light.
