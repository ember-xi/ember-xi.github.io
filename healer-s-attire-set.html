Healer's Attire Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

This cloth armor in distinctive white and red makes any white mage instantly recognizable at a distance. From the cap down to the duckbills this set uses an eye-catching pattern of red and white interlocking triangles at the hems, and adds bits of leather in key points for extra protection. For a fee you can store the set at any Armor Storer.
