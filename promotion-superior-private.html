Promotion: Superior Private

From Zenith XI Wiki

Level 75 reference · Zenith rules

Start NPC: Naja Salaheem - Aht Urhgan Whitegate (I-10) upstairs
Requirements: Obtain 25 Mercenary Rank points as a Private First Class
Items Needed:
Title: Superior Private
Repeatable: No
Reward: SP Wildcat Badge

Previous Quest: Promotion: Private First Class
Next Quest: Promotion: Lance Corporal

Walkthrough

  • Obtain 25 Mercenary Rank points.
  • Talk to Naja Salaheem for a cutscene that starts the quest.
  • Look for the Warhorse Hoofprint in Aht Urhgan areas. The Warhorse Hoofprint webpage on ffxiclopedia lists possible hoofprint locations. Do note that there can be more than one hoofprint up at a time. Unlike retail, Eden does NOT show hoofprint on Wide Scan.
  • Check the Warhorse Hoofprint for a Dark Rider Hoofprint (Key Item)
  • Return to Naja for a cutscene and your promotion.

Note: As of January 11th 2021, Superior Private is the highest rank on Eden. Speaking with Abquhbah WILL NOT trigger the next promotion quest.

Game Description

Client: Naja Salaheem (Salaheem's Sentinels, Aht Urhgan Whitegate)
Summary:

Your task is to find some hard evidence that the "Dark Rider" has truly appeared out of legend and is terrorizing the Empire.
