Runic Key

From Zenith XI Wiki

Level 75 reference · Zenith rules

This key item is received upon completion of Nyzul Isle Investigation, floor 100. This item is only received by the person whose runic disc was used to start the Assault at floor 96. Upon receipt of this key item, their Runic Disc is erased.

Current use for the key item is unknown.
