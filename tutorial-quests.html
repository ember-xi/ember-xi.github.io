RoE Trust rewards

The tutorial objectives award Ciphers in this order: Valaineral → Mihli Aliapoh → Tenzen → Adelheid → Joachim. Activate each named objective before summoning. Read the complete objective and Cipher walkthrough.

Echad Ring retired

From World Quests v3.3.1, the final tutorial step awards 12 Free Chocopasses only. Echad Ring is no longer a tutorial reward in any starting city. Existing tutorial progress remains.
