Usukane Haramaki Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A set of armor crafted from various incredibly rare and expensive items, as well as a total of 50 Imperial Gold Pieces. The Usukane set is wearable by Monks, Samurai, Ninja and Puppetmasters only, and provides large enhancements to Accuracy and Evasion, as well as Haste bonuses.


Number of Pieces: 5

Cost to store: Unknown. Storing might be possible with Ghanraam.
