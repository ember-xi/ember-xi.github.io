Valor Armor +1 Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

The pinnacle of Paladin Armor, this set surpasses that of HQ Gallant Armor in almost every way. Giving the Paladin a more invincible stature than before, this extraordinarily rare set signifies that the wearer has met the many trials of being a holy knight and exceeded all expectations. For the Normal version see Valor Armor Set.
