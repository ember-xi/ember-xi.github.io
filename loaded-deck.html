Loaded Deck

From Zenith XI Wiki

Level 75 reference · Zenith rules


Job Trait Overview

  • Game Description: Focuses effect of Random Deal on abilities waiting on recast. Has a chance to fail if only one ability is waiting on recast.
  • Job Traits are always active.
  • Each futher merit reduces the chance of failure by 10%


Notes

  • Meriting this trait ensures Random Deal will always reset an ability, provided there are 2 or more abilities that have been used and are waiting on recast timers. If there is only one ability on waiting on recast, there is a chance it will not be reset. Meriting more in this category reduces the chance of this happening.
    • The chance of failure with only one ability waiting on recast is much higher than 50% with only one upgrade in this category. It seems to be at least 70%, so 3 upgrades in this category should reduce the failure chance to about 50%.
