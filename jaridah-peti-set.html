Jaridah Peti Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A tanned armor set fashioned in the far east. All parts of the set buff up ranged attacks, making it perfect for those that prefer to fight from afar. Some pieces also buff up accuracy and/or attack, for those that prefer to get up close and personal. The high quality version of this set is the Akinji Peti Set.
