In-Depth New Player Guide by Deuce

This guide is still a WIP and may be split into several smaller guides for ease of navigation in the future.

About Eden Private Server

Eden is a FFXI private server not affiliated with Square Enix or any other company and is free to play. The server is focused on emulating the official game circa September 2008 excluding the Wings of the Goddess expansion. There are currently no plans to add this content at this time. This means the level cap is 75 and Trusts are not available; although the menu option for Trusts exists due to the client version used.

As of writing, several pieces of content from this era such as Salvage, Einherjar, ZNM, and Besieged have yet to be added to the server, but will be in the future. Patches are still being made to tweak certain game mechanics in order to achieve greater accuracy to 2008 FFXI; however, as it stands Eden provides one of the most accurate representations of 75-cap FFXI. Further information about available content can be found in the Discord or on the Website.

Getting Started

Install guide adapted from instructions created by players in the tech-support channel of the Eden Discord including Mozzy, Bliven, and others.

Installing the Game

Important Note: If you currently have FFXI installed whether its for retail or another private server then you should read this part of the guide carefully including the section Switching Between Retail and Eden.

This must be done even if you already have retail XI installed. Eden does not use the current retail client.

  1. Download the Eden installer from the pinned messages in the discord as this will have the most recent version.
  2. Unzip the installer to a location on your computer.
  3. Open the folder labeled that was unzipped and open the Application "Installer"
  4. Go through the process of installing the game files after choosing a location on a drive. By default it should be installed in a folder labeled "Eden" on your C:/ drive.

Using Ashita or Windower

Both programs are included within the Eden installer that should have been downloaded and can be found in your Eden folder after installation. These programs are used to force FFXI to run in windowed mode or borderless window as this was not natively supported by the original retail client. In addition both programs have various third party tools available, however some of these are banned on Eden, check the rules on the discord!

Ashita

Used by most players to play FFXI on Eden. A recent change to the retail FFXI client forced Ashita to update their client to fix some bugs, which in turn created some bugs for private servers running older versions of the game. This is solved by creating a specific shortcut that never updates Ashita otherwise the program will update automatically by default when started.

  1. Navigate to the Ashita folder found within your Eden folder and open it.
  2. Right click the Ashita application and choose Create Shortcut
  3. Find the shortcut on your desktop or wherever it was saved.
  4. Right-click the shortcut and select Properties.
  5. In the field "Target", add --noupdate after Ashita.exe, apply, and click OK.
  6. It's recommended to change the name of the shortcut to highlight this change.

Now you should be ready to launch Ashita, so let's do that.

  1. Open your shortcut to Ashita
  2. In Ashita there should be some default profiles, but you'll likely need to edit one of these or create your own to properly launch the game.
  3. Click on the + symbol on the bottom left to create a new configuration
  4. Change the configuration name to something you prefer, this can be changed again later.
  5. We will need to change the file under Boot Configurations, click on the three dots to browse your folders.
  6. Navigate to your Eden install folder, then Ashita, then ffxi-bootmod
  7. Select xiloader, this should be an application within this folder. If you do not have this it can be downloaded from the pinned messages in the discord and copy pasted to the ffxi-bootmod folder.
  8. In the Command field, add the text --server play.edenxi.com --hairpin
  9. If you wish to change your resolution the game runs at click on Window.
  10. Set your Window Size using numerical values, typical window sizes are recommended; 1600x900, 1920x1080, 800x600, etc.
  11. Click Save Configuration at the bottom.

We should now be able to launch the game by hitting the Play button found in or Configs for Ashita. If you are having issues such as the launcher keeps crashing and you're using any AntiVirus software then you may need to whitelist the launcher application found within the ffxi-bootmod folder. Otherwise help is best found on the discord.

Windower

The original project created to force windowed mode or alt-tabbing in FFXI. Later additions were made to allow for various 3rd party tools. Similar to Ashita, not all of these tools are allowed by Eden's rules.

  1. Navigate to your Eden install folder and then the folder for Windower.
  2. Place the xiloader application into the Windower folder. Download this file from the discord if you have not already done so.
  3. Right-click settings and open with an application such as Notepad.
  4. Add the following, <args>--server play.edenxi.com</args><executable>xiloader.exe</executable>, to your settings at the bottom before </profile>.
  5. Save the file and close notepad.

If you already had retail installed before Eden, then please skip to Switching Between Eden and Retail before launching Eden.

Launching Eden, Creating an Account & Logging In

After setting up either Ashita or Windower we should now be able to launch Eden via the profiles saved in whichever program we configured. If you had previously installed another version of the game, be sure to follow the steps in the Switching Between Retail and Eden section before coming back here.

  1. Launch the game. This should load an application window.
  2. We're given several options, Login, Create Account, or Quit.
  3. If you're a new player then you will need to create an account.
  4. This requires a code, which can only be obtained from other players via the discord.
  5. Open the Eden discord, navigate to the new-players channel, and ask for a code. Codes are given through discord DMs only by other players who are logged into Eden and capable of giving them out. Players who are level 15+ with a minimum of 72 hours of playtime on the server are able to do so. Codes expire after five minutes. Depending on time of day this can take several minutes or a couple hours if its very early in the morning in the US Eastern time zone.
  6. After acquiring a code we can enter it into the launcher. If you wish to create more than one account, you'll need a code for each one. If this is the case, be sure to ask for more than one the discord.
  7. Follow the next several steps in the launcher.
  8. A recovery e-mail isn't needed, but is helpful in case you ever need to recover your account after a lost password or account name. Remembering other information such as character names and account creation dates are also helpful to the staff assisting with account recovery.

The game should now load and we can either choose to continue on to character creation or close the client and continue setting up some other things to make our time easier when it comes to playing and/or logging in.

If you wish to continue setting up, close the game and we can do things like setting up a controller and changing some settings in Ashita so that we can automatically input our login information so we don't have to manually do it each time.

Auto-Login with Ashita

  1. In Ashita, click on the profile we configured in order to highlight it.
  2. Click on the pencil at the bottom left to edit our configuration for this profile.
  3. Find the Boot Configurations and then the Command field.
  4. After --server play.edenxi.com --hairpin, add --username YourUserName --password YourPassword
  5. Save your configuration and then hit the play button for the given profile.

If entered correctly this should now automatically login to the account using the given information after pressing the play button for the configured profile.

Controller Settings

Various controllers that are compatible with Windows can be made to work with FFXI. The game was originally developed for the PlayStation 2 and is well suited to controller play. Players are able to edit their controller configs and will need to do so in order to properly get them working before using them in game. If you wish to make changes to controller settings then all instances of the game must be closed in order to do so.

  1. Navigate to the Eden install folder.
  2. Navigate to the SquareEnix/FinalFantasyXI/ToolsUS folder.
  3. Right-click FFXiPadConfig and run as Administrator. This should open the GamePad config settings.
  4. First click on Test Gamepad to ensure that the controller being used is being detected.
  5. If it's not, be sure to check Enable Gamepad and Enable XInput and then Test Gamepad again.
  6. Once our controller is detected we can setup our button configs. Not all of the buttons or the options need to be mapped.
  7. Be sure that basic movement and camera settings are properly calibrated.
  8. Check or uncheck "Enable gamepad when game is inactive" depending on preference.
  9. Enable or disable Force Feedback. This does work in game, but only is in effect around certain large enemies when they're moving.
  10. Click Ok.
  11. Launch the Game and play the game a little to be sure everything is working based on preference.
  12. If not, close the game and make changes where necessary following the steps above.

Switching Between Retail and Eden

If you desire to play retail and Eden on the same machine then follow the steps in this guide. In order to properly play both versions of the game, certain registry values need to be changed each time we wish to switch between clients. Both retail and Eden, as well as other private servers can be played simultaneously; however, retail often causes Eden to crash when loaded second. To prevent this, load retail before Eden and this should be prevented. From here there are two branching paths which differ somewhat depending on the order of installation.

I already had Retail installed...

  1. Download and Install the Eden installer per the Install Guide above.
  2. Open the discord and check the pinned messages in the tech-support channel. There should be a message titled "How to Run 2 FFXI Installs".
  3. Per those instructions we need to download a .bat file, that should be found within the same post. This is a simple batch file which switches registry values for FFXI on your computer.
  4. Copy this file into both your \PlayOnline\SquareEnix\ & Eden\SquareEnix\ folders.
  5. Next create a desktop shortcut for each of these folders on the desktop. Otherwise you will have to navigate to these folders every time you wish to switch between clients.
  6. Run the .bat file as Administrator within your retail \PlayOnline\SquareEnix\ folder and follow the simple instructions.
  7. Load PlayOnline however you choose and login to your retail account.
  8. Load FFXI, this should require you to update the game. One way to tell the proper files are being updated is by having your \PlayOnline\SquareEnix\FinalFantasyXI\ folder open and observing the patch files towards the bottom, particularly the patch.cfg file. This file should be updating while the game is initially patching. If it is not then you are likely updating your Eden install, which will require you to uninstall and reinstall the Eden client.
  9. Play retail FFXI a bit to ensure everything is working normally.
  10. Use your shortcut to the \Eden\SquareEnix\ folder to run the switch.bat file as administrator in this folder. This will switch registry values for FFXI to Eden now. Your retail client can continue running as normal, but if you close it, then you'll need to run the switch.bat in your retail folder again before loading the retail game.
  11. Check your profile configuration in Ashita, particularly Boot Configuration and ensure the proper loader is being used.
  12. Launch Eden.

If you installed Eden first...

  1. After installing and playing retail, you will need a switch.bat file to fix registry values to play Eden again. This batch file differs slightly from the one used above.
  2. Navigate to the tech-support channel on the Eden discord.
  3. Find the Switch_to_Eden.bat file posted by Bliven in response to Blu. Searching "oh then you need this" should help you find it easily.
  4. Download this file and place it into both your \PlayOnline\SquareEnix & \Eden\SquareEnix\ folders.
  5. Create shortcuts to both of theses folders for easy navigation.
  6. Run the batch file in your \Eden\SquareEnix\ folder as administrator and follow the instructions.
  7. Load Eden and check that everything is working properly.

Now that you have multiple installs of the game working it is important to remember that one must always use the switch.bat file found in each specific install folder as administrator before running that version of the game. If you wish to easily switch between FFXI clients while multiple are running then it is best to download FFOSwitchMon from the discord and begin using that.

SwitchMon

FFOSwitchMon is a third party program that allows for easy switching between FFXI windows while using a controller. It allows players to map buttons for cycling backwards or forwards between game windows only. Due to it not being updated in some time it has a few minor bugs, so it's best to always exit and restart the program each time when you play.

  1. Download FFOSwitchMon from the links in the Eden discord.
  2. Place the folder wherever desired.
  3. Open the folder and create a shortcut for the application if desired.
  4. Run as administrator.
  5. Click on the Gamepad tab to assign buttons.

Any new FFXI game windows will be automatically detected by SwitchMon.

If you wish to prevent switching to one or more windows you can...

  1. Right-click on the application found in your system tray on Windows and select settings.
  2. On the General tab, right-click any character or window you wish to lock or unlock.
  3. Select Allow/Deny

Having Issues with FFOSwitchMon?

Some users have reported an issue with SwitchMon not working even after following all of the instructions found in the ReadMe included with the downloaded program. This is typically reported by players using Xbox One controllers in Windows. If SwitchMon does not work you may need to download an additional file named XInputPlus, this can be found on the discord. This file will modify the config settings of FFOSwitchMon and download multiple dll files that will be placed into your FFOSwitchMon folder. To do this, follow the instructions below:

  1. Download XInputPlus, links to which can be found from searching for it on the discord.
  2. Extract the download to a location on your computer.
  3. Run the application "XInputPlus".
  4. Select FFOSwitchMon as the target program.
  5. Choose "Enable directinput output" found under the directinput tab.
  6. Enable all the .dll files under Settings / DLL files, click Apply.

If you are still having issues after this "Fix" please visit the tech-support channel on the discord.

Troubleshooting

Some players have reported various issues with connecting properly to the Eden server. If your launcher keeps crashing when loading the game, be sure any AntiVirus software isn't killing the program and preventing it from running. If it is, whitelist it. This guide isn't going to be able to cover all of the issues and their solutions without becoming very convoluted. The best place to find help is within the discord, particularly in the tech-support channel. Check any pinned messages and try to do a few searches for your problem before asking for help.

Account Recovery

Are you a returning player who no longer has access to their login information? Visit the discord and type "account recovery" in the tech-support channel. A discord bot will respond to your message with instructions for requesting a password reset. Please note, it may take up to several days for an Eden staff member to respond to your request. Insufficient information may make it difficult if not impossible to reset any information for the account in question.

Creating a Character

Races

There are five playable races in Final Fantasy XI. Similar to other early MMORPGs such as Everquest, which XI was heavily inspired by, the races possess stat differences that players who min-max may wish to pay attention to. Although, by no means does one have to choose the race best suited to one job or another. Aesthetic preferences are arguably more important to most.

Elvaan

Long necked and proud, Elvaan call San d'Oria home. Possessing the second highest HP and second lowest MP make Elvaan good for a few specific roles including tanking and meleeing. Their lowest INT in the game makes them the worst Black Mages, however, they have the highest MND stat which make them good White Mages. High VIT coupled with their HP, make them good Paladins.

Galka

Big and burly, Galka have taken refuge in Bastok for many years. The highest HP and strength makes Galka strong and powerful as melee or tanks. The second lowest INT with the second lowest MP makes them mediocre Black Mages, but with many options for converting HP to MP later in the game they can make decent Red Mages.

Hume

Average and unassuming, Humes are the founders of Bastok. Being average has its advantages and disadvantages, so while Hume don't particularly excel at any job they can perform well enough to not be hindered from low stats in one category or another.

Mithra

Fierce and independent, Mithra made Windurst their home away from home. The second highest MP, the highest DEX, and second highest INT makes Mithra good for playing melee as well as mages. Thief particularly benefits from their high DEX as well as Samurai and Dark Knight, which both have weaponskills that use DEX as a modifier.

Tarutaru

Small and quirky, Tarutaru built Windurst with magic or something. The highest INT, the highest MP, the lowest HP, the lowest VIT make them perfect for glass cannon play as a Black Mage. While their small stature and low STR may dissuade one from playing melee, it is still possible, but if you wish to tank then this may not be the best choice especially during early levels.

Starting Jobs

New characters are only able to choose from one of the six starting jobs available during character creation prior to level 30. Choosing one job does not lock you into that specific job until 30. A player can immediately change their job to one of the other six inside the Mog House upon starting the game.

Warrior

A pure melee, Warrior is one of the easier jobs to level early on. Provoke, which is a job ability earned upon reaching level 5 is often in demand by parties. Warriors have access to equipping ranged weapons at level 1 that make leveling to 10 significantly faster and easier. It is one of the best melee jobs in the game at 75 when properly geared.

Monk

Another pure melee, Monk is easy to level to 10 and is the best subjob for Warrior and Thief until Ninja can be unlocked at 30. Boost, earned at level 5 raises the player's attack for one swing and is useful for boosting damage marginally, but it can be used every 15 seconds. Above level 20, Monk can have a difficult time finding parties due to their lower utility and damage. At 75 Monks won't be in as high of demand until Salvage is released on the server.

Thief

A somewhat mediocre melee job that is often overlooked for better melee by parties. This makes earning EXP for it somewhat frustrating as the most consistent option are arrowburn parties in Korroloka Tunnel at level 15. It's greatest value comes with its job specific trait Treasure Hunter obtained at level 15, which can be raised through levels and gear up to Treasure Hunter IV at 75. A Thief will always be in demand when a group is aiming for something rare to drop that is not obtained via a treasure chest. If you enjoy farming, having Thief leveled can be quite valuable even as a sub job for Treasure Hunter 1 and Flee.

White Mage

A pure healer, White Mages are quite useful early on due to access to Cure II at level 11. Other spells such as Poisona, Paralyna, and other -na spells, which remove status ailments are accessible only to White Mages as a main or sub job. However, due to focusing on healing magic, their offensive capabilities are quite limited. This makes leveling to 10 or 11 somewhat time consuming relative to the other five starting jobs. Also, because all spells are obtained through either questing, mob drops, or NPC shops, this can make them more expensive to level early on.

Black Mage

A pure offensive magic caster, Black Mage is useful in a lot of Endgame content due to their high burst damage. Unfortunately, getting to said content or level 75 can be quite the grind. Black Mages after level 20 rarely receive invites to normal parties. While there are regular Black Mage parties active on Eden at all hours, there can be lines to join them, and relative to exp earned in normal parties it can be quite the grind. One advantage/disadvantage though is these parties are relatively straight forward and always level sync from 20 to 24. Unfortunately, this will require Black Mages to skill up their magic skills later on, something most melee, support, and healers will have to do less often. Soloing on Black Mage is possible at a certain point, but it can be slow and is really only recommended to those most dedicated to learning the ins and outs of Black Mage solo exp. Similar to White Mage, Black Mage has to often buy their spells and because of the rarity and difficulty to obtain some black magic, it is the most expensive.

Red Mage

Often used as a healer, Red Mage can be found in place of a White Mage in many instances. After level 41 when Refresh can be learned, and later Haste at level 48, Red Mage becomes the primary healer of choice for a majority of experience parties. Due to possessing the highest enfeebling magic skill rating and the best gear for it, Red Mages are quite useful at endgame and lowmanning content. Their overall utility is the greatest in the game, whether it's healing, enfeebling, chainspell stunning with Dark Knight sub, or tanking using Ninja sub, Red Mage can do just about everything other than damage. Although, this does not mean they lack offensive spells, as they have access to tier III black magic. A Red Mage and just about any other job in a duo can be a powerful combination.

Home Nations

There are three starting nations that players can choose from when beginning the game. These choices are not permanent and can be changed for an in-game fee later on.

San d'Oria

Home of the Elvaan, the Kingdom of San d'Oria is a good choice for new players. Often in 1st Place during Conquest with ownership of valuable outposts, San d'Orian citizens won't have to struggle too hard to get where they need to early on, including the Valkurm Dunes. It also has easy access to some decent places to farm items for selling on the auction house. The Leathercraft, Woodworking, and Smithing guilds are located here.

Bastok

Respite of the Humes and the Galka, the Republic of Bastok is arguably the most popular choice for players to settle on Eden. Bastok often challenges San d'Oria for 1st Place in Conquest. Most outposts are easily obtained by players from this nation, but reaching Valkurm Dunes is slightly more treacherous than San d'Oria. The Goldsmithing, Smithing, and Alchemy guilds can be found here.

Windurst

Sanctuary of the Tarutaru and Mithra, the Federation of Windurst is the least popular nation on Eden. Due to its lack of popularity Windurst is rarely in 1st Place during Conquest. This position often forces Windurst players to band together and focus specifically on obtaining certain Outposts. One common dislike of Windurst by most is that it has a sprawling layout relative to the other two nations. Also, being on the opposite continent of Bastok and San d'Oria requires Windurst citizens to travel to Valkurm Dunes via the ferry found in Mhaura. The Bonecraft, Clothcraft, Cooking, and Fishing guilds are found here.

Choosing a Name

There is a character limit for names in FFXI, 16 characters, with only the first character being capitalized and no special characters. Players with offensive names may eventually be contacted by a GM and given the opportunity to rename said character to something non-offensive.

Completing Character Creation

After choosing your race, character appearance, job, nation, and name, you'll be able to start the game. The first time a new character loads into the game they will be shown an unskippable cutscene overviewing the nation they have selected. Once this completes players will immediately be in a conversation with a starter NPC that has some basic information.

Warning: The default volume levels in-game are set to max and cannot be adjusted until after viewing the initial cutscene. Consider turning down your desktop volume.

Beginning the Game

Final Fantasy XI is an older MMORPG first developed for the PS2 and then ported to the PC. Due to these factors the gameplay and UI and feel a little archaic and clunky at times. Before we get to adventuring, we should familiarize ourselves with various configuration settings.

Config Settings

There are a few configuration options available on the main menu screen of the game, which are limited to changing settings for this menu.

In-Game

Open the menu by pressing the "-" key and navigate to Config, using the arrow keys. Opening Config will display multiple options. Begin by opening the Gameplay menu, this is where we can adjust the game volume and turn on inventory sorting. In addition we can adjust the gamma settings, but these are best left on the default setting.

Window Settings

Open the Window menu and then Shared. Here we can enable multi-window, timestamps, change window type, and turn off window effects.

Multi-Window

If you wish to use multi-window, select either vertical or horizontal, whichever you prefer. Horizontal mode will require resizing the window width, which can be done individually for each window in their respective menus. In addition we can set our minimum and maximum lines as well as the decay rate of our windows.

Logs

If we wish to adjust which text is displayed in each window we can do that in this menu. Turn ON or OFF settings in each window to move chat from one to another.

Misc. & Misc. 2

These menus have options for shadows, weather effects, and other graphical settings. In Misc. 2, be sure to match your aspect ratios between your game window resolution and the setting in-game.

Misc. 3

Turn on Area Display, Party Icon Display, and Timer Display

Communication

  • /say, /s - Type in say chat.
  • /shout, /sh - Type in shout chat. Zone wide communication.
  • /yell - Type in yell, limited to one yell every 15 minutes. Primarily used for global communication to find parties or sell/trade items. Inappropriate yells can lead to a player being muted in this chat group.
  • /party, /p - Type in party chat. Visible to anyone in your party or alliance.
  • /tell, /t - Whispers a specific player, ex.: "/t PlayerName message here"
  • /linkshell, /l - Type in linkshell chat for the linkshell equipped in slot 1.
  • /linkshell2, /l2 - Type in linkshell chat for the linkshell equipped in slot 2.
  • /cm * - Sets a specific chat group as your default. The default upon logging in is always /say. ex.: /cm s, /cm p, /cm l, /cm l2
  • /echo - Only visible to oneself.

Responding to tells can be easily done by pressing CTRL + R. Holding CTRL and pressing R over and over will cycle through previous players whom we shared private conversations with.

Server Commands

Type !menu in-game to bring up a list of commands available to all players on the server.

Need a GM?

There are several players who also act as GMs for Eden. If you ever need assistance with anything that cannot be handled via server commands and the issue is in-game, then submit a ticket to the GMs. This can be done by opening the menu and navigating through to Help Desk > Help Desk > I can't Move > Other > I would like to call a GM. GMs are volunteers and there are many who play on the server, so response times may vary. Please be patient when waiting for a GM.

Tutorial NPCs

As of mid-April 2022, tutorial NPCs were added to Eden. Characters created after this date will have the option to complete a series of quests designed to guide new players through a few game mechanics. While it is not required to complete them, some players may find the early rewards and information useful. The NPCs can be found at the following location:

  • Alaune - Southern San d'Oria (G-10)
  • Gulldago - Bastok Markets (D-11)
  • Selele - Windurst Woods (K-10)

Earning EXP

Experience is primarily earned through defeating monsters that rate from Easy Prey to Incredibly Tough. It is possible to gauge a monster's difficulty through the check command in the battle menu that is displayed when selecting a targeted monster. Enemies which check as Too Weak will not give any experience.

  • Too Weak - 10 levels or below the player's current level. Do not give experience points, drop crystals, or conquest points.
  • Easy Prey
  • Decent Challenge
  • Even Match
  • Tough
  • Very Tough
  • Incredibly Tough
  • Impossible to Gauge - typically reserved for Notorious Monsters, these enemies will be tougher than those of the same level; however, they will always check as this even if the player is well beyond their level.

Note: Players will begin losing experience upon death at level 5, the penalty will increase with subsequent levels gained. This maxes out at 2,400 exp lost at 75. The White Magic spells Raise, Raise II, and Raise III will reduce the amount of experience lost when compared to going back to a home point.

Beastmen's Seals

From the beginning of the game players will find a golden looking coin that drops from enemies. Be sure to save all of those which drop to your inventory. If they're sitting in your treasure pool because of a full inventory, then throw away something such as a bat wing or flint stone to make room. They will be used later in exchange for Orbs used to enter Burning Circle Notorious Monster battles that can drop good loot. Beastmen Seals can only be obtained once every 5 minutes from enemies which give experience. In parties the common rule is to allow these to drop randomly unless a party is in the process of disbanding at which point it is usually customary to lot on them.

Level 1-10

Before EXPing be sure to grab Signet from a gate guard in your nation, found near the main exits. This buff provides several benefits including the accumulation of conquest points, crystals from enemies, increased healing HP while resting, no TP loss during rest, among others. Never leave town without refreshing it, while it should last several hours it can be disappointing when it wears off.

Prior to level 10, most experience will be earned solo; even though, you can party up with others beginning at level 1. Partying only seriously begins around level 10 or 11 when players have access to better spells and abilities useful in group play such as White Mage's Cure II. At level 1 mobs which are level 1 and an Even Match will be considerably weaker than even those which are level 2 or 3. As you level up mobs will become stronger relative to the player meaning that at level 10 an Even Match enemy will be a difficult solo even for most melee jobs. This is why you will often see players who are level 7-9 still fighting level 1-3 mobs. Due to their lower HP, level 1 mobs tend to be much faster to kill than even those which are only level 3 or 4.

Recovering HP and MP

Resting is vitally important while leveling. It is the only way to recover HP and MP without the use of items, equipment, or spells most of which are only available in later parts of the game. Also, when a player levels, their HP and MP will instantly recover back to full. Resting can be achieved in multiple ways:

  • Pressing the "H" key on the keyboard.
  • Pressing "*" on the numberpad.
  • Pressing the left thumbstick of the controller. (Custom controller settings may change this.)
  • Typing /heal

All of these will perform the same action and cause your character to go into a race specific pose to begin recovering HP and MP incrementally over time.

Level 10+

Solo experience after this point is usually only reserved for slowly killing Easy Prey enemies by most jobs especially mages. Some jobs such as Summoner, Puppetmaster, and some melee can choose to solo tougher enemies based on their ability and gear while Beastmasters tend to often solo or party in groups of 2 or 3. While it is possible for Black Mage to solo EXP in some instances later beyond level 30 to 40, most other jobs will primarily earn their experience from partying.

Recommended: Before deciding to join a party, it can help to level more than one job to level 10. This is in order to make some more money for the main job you wish to level. Players will need to do this for their subjobs anyways, so it can help to tackle this earlier on. If those who play mages are feeling ambitious they can level Warrior and/or Thief to 10 for an easier time farming solo early on in the game.

Valkurm Dunes

When you are level 10 or ideally level 11 you should begin seeking for a party, see Partying, and begin venturing your way towards the Valkurm Dunes. The dunes are the first place most players will party for the first time and is where most will earn experience from 10-18. Located in the Zulkheim region and accessed by...

  • San d'Orians from the south side of La Theine Plateau
  • Bastokans from the north side of Konschtat Highlands, there will always be bats in the tunnel which divide Konschtat Highlands from the main area of the map. Bring a form of sneak to make your way through more easily.
  • Windurstians from Selbina by way of the ferry from Mhaura, accessible from Buburimu Peninsula, which itself is located on the east side of Tahrongi Canyon.

Sneak and Invis which can be obtained from Silent Oil and Prism Powder respectively (purchased under Medicines on the Auction House) are recommended for safe and easy navigation of the dunes in some sections.

In addition, you may want to obtain outpost supplies from a gate guard before you head out. Check the Conquest map by opening the Region menu option and determine which nation owns the outpost in the Zulkheim region. This outpost is located in the Valkurm Dunes and can be used to easily teleport back and forth from your home nation via the warp NPC, explained further in the Outpost Warp section of this guide.

After the dunes players will venture to various other camps found throughout the world. More information about different camps can be found in this guide.

Subjob

While in the dunes be on the lookout for your subjob items; Magicked Skull, Crab Apron, and Damselfly Worm for the quest Elder Memories started in Selbina. There is another similar quest, The Old Lady, in Mhaura which asks for a completely different set of items.

Experience Rings

There are several rings in the game that can be obtained to temporarily boost a player's ability to earn EXP through an item enhancement. Players must equip the ring, wait 30 seconds, and then use the item. A charge a will be consumed after which the ring can be unequipped with the status effect remaining active. All of the following rings can only be used once every 16 hours!

  • Chariot Band - Purchased from your nation's guards for 500 Conquest Points, provides a bonus of +75% that lasts 90 minutes, which caps at 500 experience earned. 3 Total Charges for a bonus of 1,500.
  • Emperor Band - Purchased from your nation's guards for 2,000 Conquest Points, provides a bonus of +50% that lasts 210 minutes, which caps at 2000 experience earned. 3 total charges for a bonus of 6,000.
  • Empress Band - Purchased from your nation's guards for 1,000 Conquest Points, provides a bonus of +50% that lasts 180 minutes, which caps at 1000 experience earned. 7 total charges for a bonus of 7,000.
  • Anniversary Ring - Only available in May to characters created prior to the anniversary event on Eden. Provides a bonus of +100% that lasts 720 minutes, which caps at 3000 experience earned. Obtained via an event moogle near one of the gates in your nation. 10 total charges for a bonus of 30,000.

Other than the Anniversary Ring, all of the rings mentioned above can be recharged once per conquest tally (weekly) by trading it to a gate guard NPC for less than the cost of purchasing a new ring. However, the game will only allow you to hold one of the rings from conquest NPCs in your inventory at a time.

Gameplay

Combat

By modern MMORPG standards FFXI's combat is a bit slow and clunky, especially when playing without a controller. As you play the game you will want to familiarize yourself with the macro system in order to make the gameplay smoother and an overall more enjoyable experience.

Enemy Behavior

Before engaging in combat it is important to understand how monsters behave. Early on in the game the majority of monsters will be non-aggressive to players unless attacked. The primary exception are the beastmen; for instance, Goblins, Orcs, Quadav, and the Yagudo. Except for the Quadav who aggro by sound, these beastmen initially encountered in the game will all aggro by sight. At night players may also come across undead enemies. Skeletons and ghosts mainly, which aggro by sound and low HP from a greater range, so be careful of your proximity to them. Additionally, some mob types aggro by magic casting, notably Bombs and Elementals. Lastly, later in the game the player will encounter mobs which aggro the use of Job Abilities, as well as those which aggro through the effects of sneak and/or invisible, referred to as True Sight and True Sound.

Linking

Some monster types will link with one another if they notice a player engaged to one of their family type, saplings and lizards are two examples. All beastmen will link with one another from the same family. Linking is based on the method of detection that a monster uses. For example, a monster which detects by sound and links will cause a link if another of the same type is within a certain range. On the other hand, monsters which detect by sight and link can be standing immediately next to one another with one being aggroed while the other is facing away. In this instance, the other monster will not detect the player having aggroed the other monster and will not link.

Targeting

There are a few methods of targeting NPCs in FFXI:

  • Pressing F8 on the keyboard will target the closest NPC to the player. This includes both monsters and non-aggressive NPCs, as well as doors, ???s, and other misc. targets.
  • Pressing Tab on the keyboard will cycle through all NPCs and PCs nearest to the player from left to right.
  • On controller, pressing the confirm button will target the nearest NPC or PC to the player.
  • On controller, using left or right on the Directional Pad will cycle through NPCs and PCs by splitting your field of view in half. The Left D-Pad will target NPCs on the left half of your screen and the Right D-Pad will target the right half.
Attacking Enemies

There are two main methods of attacking or engaging enemies for combat in FFXI:

  • Open the menu while targeting an NPC and confirm the attack option. This will draw your weapon and lock your camera onto the targeted enemy.
  • Typing /attack and pressing enter while targeting an enemy will engage and similarly draw your weapon and lock your camera.

Later in a party, the player can type /assist PlayerName, which if said player is engaged to an enemy will cause your character to target and engage the same enemy.

Two Helpful Tips:

  1. Running in the same direction and in front of a moving target while engaged will allow you to swing causing them to stop moving.
  2. Ranged weapons are a great tool for initially attacking monsters which leads to less moving around. Mages can use magic to achieve similar results.

Weaponskills

In FFXI the majority of melee combat is done through auto-attacks except when a player has greater than 1000 TP, which can be used to perform a weaponskill. Auto-attack speed is determined by a formula which calculates the delay of the weapon being used, traits, and haste.

Weaponskills are learned automatically based on the combat skill for the weapon being used, ranged weaponskills can only be used by Rangers and Corsairs, except when equipped as a sub.

  • To use a weaponskill, while engaged to an enemy, open abilities, then open the weaponskill menu and select one of the weaponskills which have been learned, confirm to use.
  • Alternatively, typing /ws "WeaponskillName" <t> will use the specified weaponskill.

To view your combat skills, open the menu, go to Status, and select combat skills.

Note: Due to an occasional bug, your combat skills may not immediately uncap upon leveling. To fix this, go into your equipment and unequip and then re-equip your weapon.

Ranged Attacks

In order to use ranged attacks the player must equip a ranged weapon and any relevant ammo. Performing a ranged attack can be done by one of two methods:

  • Using the menu, opening abilities, select ranged attack, and confirm.
  • Typing /ra <t> which will use a ranged attack on the enemy that is currently targeted.

Abilities

Job abilities are specific to each job and learned at various levels. Some jobs such as Red Mage, Black Mage, and White Mage have few Job Abilities while others such as Thief or Samurai can end up with many more than those three combined. Typically melee jobs will have more job abilities than mages. Subjobs will give the player access to the abilities available the level of said subjob, albeit in some instances in a reduced state. Two-hour abilities from a subjob cannot be used.

  • Job abilities can be used from the combat menu, opening abilities, selecting Job Abilities, then selecting an ability, and confirming to use.
  • Typing /ja "JobAbilityName" <me> or <t> depending on the ability.

Spells

Spells are learned from the use of scrolls, which can be obtained from enemies, quests, treasure chests, purchased from NPC shops, or the auction house. Purchasing from the auction house should be reserved for spells that cannot be obtained from NPC shops or easily farmed unless there is an urgent need to acquire said spell. Once learned by a character that spell will be able to be used. The potency of magic spells are determined by magic skill, which can be viewed by opening the main menu, selecting Status, then selecting Magic Skills.

  • To cast a spell, open the combat menu, select Magic, scroll through the list of learned spells, select a spell, select a target, and confirm to begin casting.
  • Typing /ma "SpellName" <t> or <me> or <stpc>. <stpc> is used to cast on other players, more will be explained in the section on Macros.
White Magic

Healing, Divine, Enhancing, and Enfeebling Magic.

Black Magic

Elemental, Dark, and Enfeebling Magic

Summoning Magic

Most Summons must be obtained through completing various quests. Level six fame is required to begin the quests for the Prime versions of avatars. These quests require higher level players to complete. For new players there are mini versions of the fights involved in these quests that grant the use of less powerful versions.

Ninjutsu

Spells for Ninja, often used by other jobs while subbed.

Songs

Effectiveness determined by Singing, Wind, String skills. Singing skill increases both Wind and String skills.

Blue Magic

Used by Blue Mages and learned differently from all other forms of magic in the game. Blue Mages must fight enemies that use the spell or ability they wish to learn. This process can sometimes take significant amounts of time, because even if an enemy uses an ability one wishes to learn, learning it is actually random. Continue fighting these enemies and you'll eventually learn what you're after.

Inventory

On Eden players only have access to the main inventory and mog wardrobes while outside the mog house. While the menu contains other inventory options such as Mog Sack, Case, and Satchel, none of these are enabled on Eden as they were later additions to the game. Initially, the player's inventory will have 30 slots. This can be later expanded, five slots at a time, through quests received in Lower Jeuno known as the Gobbiebag Quests. Players can only unlock a total of 60 inventory slots.

Mog Safe

Players on Eden start out with access to two mog safes of equal size, 50 slots each. These spaces can be expanded three times through quests received from the moogle found within the mog house. After each quest is completed the mog safe will be expanded by 10 slots. If all three quests are completed then the Mog Safe will reach its maximum size of 80 slots. To receive these quests specific beds must be placed inside the mog house:

  • Bronze Bed - Completing this quest expands the mog safe from 50 to 60 slots.
  • Mahogany Bed - Completing this quest expands the mog safe from 60 to 70 slots.
  • Noble's Bed - Completing this quest expands the mog safe from 70 to 80 slots.

After placing the bed, player's must wait until the next conquest tally occurs before the moogle will ask them for a favor, initiating a quest. Only one quest can be completed per conquest tally; however, they can be completed back to back. Certain levels of fame are required to receive each quest with the first requiring level three fame in one's home nation.

Storage

Storage is obtained via the placement of furniture inside the player's mog house. Each piece of furniture adds to the total storage space based on the number seen on its item description. Storage caps at 80 slots, additional furniture will not increase this amount beyond this point.

Mog Locker

To gain access to a mog locker, players must be able to visit Aht Urhgan Whitegate, reachable after level 30 and obtaining access via the Tenshodo. Once in Aht Urhgan players must complete the second mission for Treasures of Aht Urhgan, Immortal Sentries, and then speak to Fubruhn outside the Mog House in Whitegate. Mog lockers are leased to the player and require Imperial Bronze Pieces to extend the lease. Players start with 30 slots and can expand this 10 slots at a time to a maximum of 80 slots. To expand Mog Locker capacity trade the following to Fubruhn:

  • Expand to 40 Slots - 4 Imperial Mythril Pieces
  • Expand to 50 Slots - 2 Imperial Gold Pieces
  • Expand to 60 Slots - 3 Imperial Gold Pieces
  • Expand to 70 Slots - 5 Imperial Gold Pieces
  • Expand to 80 Slots - 10 Imperial Gold Pieces

A conquest tally must occur between each expansion.

Wardrobes

Currently there are three wardrobes which players on Eden can unlock by completing various content. Players can place equipment including ammo into their wardrobes alleviating inventory space. Each wardrobe has 80 slots.

  • Wardrobe 1 - Reach Rank 3 and speak to the moogle found within the Mog House.
  • Wardrobe 2 - Reach Rank 6
  • Wardrobe 3 - Fully Complete both Zilart and CoP storylines including their epilogues.

Making Gil

Gil to fund adventures is one of the first challenges a new player must overcome. Options will be limited, especially at level 1 as the primary method of earning gil is by selling drops to others on the Auction House or completing certain repeatable quests, both of which require defeating enemies. There are a few options that can be done at level 1 without venturing outside the city gates, but these methods, Fishing and Mining, often require some invested gil to begin with. While there is Gardening, this takes a reasonable investment in both time and money before one will begin to see decent returns.

Where to Begin

Adventuring outside and beginning to gain experience is where all players should start. Don't forget to receive signet from a gate guard and have auto-sorting of your inventory turned on. If you see a treasure pool while solo, this means your inventory is full and the game is waiting for you to sort it before depositing the items to you. The treasure pool has a maximum of 10 spaces and items that drop and are found within it will remain for 5 minutes before falling to the ground forever. While earning experience crystals will drop occasionally from enemies, these are used frequently by crafters, and are a good early source of gil, fire crystals especially. Most items you receive early on will be of little value except in stacks of 12.

The item search function on the Eden website is a quick way of finding out the value of items you come across.

Fishing

Enough gil to buy a fishing rod and some bait, 3,000-15,000g. Fishing rods can be found under weapons on the Auction House. The most common fish for players to target early on is Moat Carp, used in the Lu Shang's fishing rod quest. These can be caught easily at zero skill around San d'Oria and Windurst. If a player wishes to delve deeper into fishing then there are several resources one should become familiar with. This includes several fishing guides which have recommendations for when and where to skill up on certain fish. Fishing can be a great activity for those who are new to dualboxing or who wish to relax and watch a TV show or movie while slowly accumulating some gil.

Gardening

About 18,000 gil is adequate to get started, but you can begin with as little as 2000g to buy a single pot, a wildgrass seed, and a few crystals. Use this gardening guide to learn more. Gardening requires patience and care, it will take 7 days before first harvest, and another 7 days before you will begin to see profits. Per Eden's rules players can only garden on three characters with a total of 30 pots, 10 per character. The game has a limit of 10 flowerpots in each character's mog house.

Mining

Getting started properly is quite expensive, about 35-40,000g to purchase the Field Tunica, Boots, and Gloves, the legs are not needed for mining. This cost can be postponed if the player chooses to mine without the gear, break rates on pickaxes will increase significantly as a result. Below are the initial areas players can easily mine:

  • Zeruhn Mines can be accessed safely from Bastok Mines at level 1. Iron and Zinc ores are the primary spoils.
  • Yughott Grotto, near San d'Oria, accessed from Ghelsba Outpost; Iron, Zinc, Darksteel Ores. Recommended level 30+
  • Gusgen Mines, connected to Konschtat Highlands, can be mined with Sneak and Invis. Darksteel and Iron ores.

There are a few other areas players can mine, but each will require a form of Sneak and Invisible from even level 75 players. Alternatively, since there is nowhere to mine near Windurst players can harvest in Giddeus, recommended level of 30 to avoid aggro.

Auction House & Bazaars

There are a few methods of buying and selling goods while playing the game. This includes the Auction House, player Bazaars, and NPC shops. Each of the three starting nations has their own auction house. On Eden these are all linked together as well as all other auction houses in the game. While not a feature originally in the game, this was done for a better functioning economy on Eden. Auctions are blind bids, meaning the only information to buyer and seller are the previous sales. The least expensive item will always sell first regardless of bid.

Players can list an unlimited number of items; however, checking the Sales Status when there are more seven or more items listed will cause a bug that requires zoning. This bug only prevents players from listing additional items until they have zoned. Items will be de-listed and returned to sellers if not sold within 30 days.

Macros

Macros play an integral role in the gameplay of FFXI. While the entire game can be played from the menus available in the game, macros make most things quicker and smoother. All new characters begin the game with a default a set of macros, which do various things. These can be either edited or deleted outright.

Macros are separated by macrobooks and then further divided by macrosets. Players have access to 20 books containing 10 sets of both 10 ALT & 10 CTRL macros, providing us with a total of 4000 possible macros. Only one book of sets may be accessed at a time without manually switching through the use of inputs or macros

How to Create a Macro

Open the menu and navigate to macros and select edit macros. This will open our list of books. By default all books will be named as "Book#", these can later be changed. Select a book with macros we wish to edit, select Confirm, and confirm. This will open said book to our current set number.


To change macro sets or macros in this menu...

  • On Keyboard, navigate with the arrow keys
  • On Controller, use the D-Pad

Once we've found and highlighted the macro we wish to edit, confirming will open a new window with seven configurable lines. The smaller top line is the macro name, the six larger lines are where we will place our macro commands. Anything input on these lines will only be permanently saved upon logging out.


To exit this window to configure another macro, press ESC on keyboard or the "cancel" button on controller.

Equipsets

Equipsets are a subset of macros, but are worthy of their own section to explain their use in greater depth. The main function of these is to change equipment with the use of macros beyond the capability of a normal macro. Instead of changing each piece of equipment with a single line in a macro, we can change every piece of equipment with a single line by using an equipset. Both Ashita and Windower contain plugins which perform the same function of equipsets with more features and a higher degree of complexity.

How to Use an Equipset

In the same Macros menu, the option to "Edit Equip. Set" can be found, select it. Similar to Macrobooks there is a list of 20 equipsets; however, unlike macro books we can change to another page. There are five pages in total allowing for the use of 100 equipsets. This number is adequate for gameplay as a new player, but as you begin to level more jobs and do more content you may find this number being insufficient. At that point it may be best to look into either Ashitacast or GearSwap for Ashita and Windower respectively.

When we select an equipset to edit, we see many of the same options as well as three others, Use Current, Equip, and Style Lock. Style Lock is not enabled on Eden. Use Current will save the selected equipset with our currently equipped gear. Equip will equip the currently selected equipset.

Configuring an Equipset

To configure gear for an equipset simply select the "Edit" option. This will open a window in which we can place gear from our wardrobes or inventory. In addition, there are two options, "Remove Piece" and "Keep same piece". "Remove Piece" will place a red X in that equipslot, "Keep same piece" will leave it empty.

Once we've chosen our equipment we can exit the window. At this point we should be sure to remember the number of the set we changed, as this will always remain the same and be used when equipping said set. We can also change the name of the set based on our preference. After configuring all of our equipsets we can begin by adding them to macros. Some examples include...

Partying

Parties in FFXI are a core aspect of the game. A party consists of 2 to 6 players with alliances being formed by 2 to 3 parties for a total of 18 players. To start a party one player must send invites to others who then have to accept them. After the first player accepts an invite a party will be formed, which subsequent players will join, up to total of 6. Parties and alliances share monster claims and loot pools with the notable exception being Dynamis which is zone wide loot.

  • Party Leaders are denoted by a yellow name in search results.
  • Party Members or players currently in a party will have their name in light blue.

Joining a Party

Before we can join a party others must know that we are seeking. This can be done through one of two ways:

  • Typing /invite or /inv
  • By going into the menu, navigating to the Party menu, and selecting seek party.

Either action will put our party flag up which will make our character more visible to others attempting to form a party. To stop seeking a party one of the two actions can be repeated to remove the flag. Consequently, joining a party will also drop our flag. When our flag is up players will only be able to see the job we are currently on, so be mindful of switching jobs while seeking a party.

Accepting an Invite

There are a two methods of accepting party invites:

  • Open the Menu, navigate to Party and select "Yes". Selecting "No" will decline the invite.
  • Typing /join, declining an invite can be done by typing /decline.

It is often customary for players to send a /tell to a player before sending them an invite asking if they'd like to party. The easiest way to respond to these messages is by pressing CTRL + R. This will respond to the last person who messaged you. Conversations with players can be cycled through by holding CTRL and pressing R over and over to cycle whisper targets.

Leaving a Party

It is best etiquette to inform our party that we need to leave well before the time to do so, with emergency situations being the exception. At least 15 minutes, but 30+ minutes prior to us leaving is recommended assuming it is possible to know this ahead of time. This information should encourage the party leader to prepare a replacement for us by the time we leave. While it is possible to find a replacement for yourself, most party leaders would prefer for you to ask before doing this. When it is time, leaving from or disbanding a party is quite simple...

  • Navigate to the Party menu and select disband
  • Type /pcmd leave

If all other players have left our party, the party will still exist with us remaining as the leader. To remove this just disband the party using one of the methods above.

Search Comments

SeaCom are a great way of informing other players about your intentions. Players who have a search comment will have a colored dot to the left of their name in the search results. These dots are color coded with experience related search comments being green. To view a player's a search comment simply select their character from the search window.

To create our own we will open the menu and open the Search option. At the bottom of this menu will be the option Edit Comment, select this option. The next menu will have multiple types to choose from with differing colored dots. We will want to use the top option, EXP Party. There will be three options in the next menu, it doesn't matter which one is selected as they all share the same text window. Selecting an option will pop up a text window that can be typed in.

In this window we can type anything we want on the three lines up to the character limit. When seeking a party we can inform players about certain information such as the subjobs we have leveled, what camps we are okay or not okay with, how low we're willing to level sync, and so on.

Inviting Players

In order to invite other players to a party a search must be performed. We want to primarily find the other players seeking a party. The easiest way to do this is through typing /sea all inv. This can be modified by adding a level range at the end, for example /sea all inv 40-65, which will return results including all players seeking a party between the level range specified.

Once we have done our search and found a player we wish to invite it is best to ask them via a /tell whether or not they would like a party specifying the level and the camp. For example, "41 Level Sync party Altepa desert", or using auto-translate "Party Do You Need It? Level Sync 33 Zi'Tah". If the party has a Bard and/or a Corsair it helps to include this information in your /tell. In this case, "Party Do You Need It? Level Sync 33 Zi'Tah have BRD" or "have BRD+COR". Parties with one or both of these supports will entice players to join your party, but they are not necessary to earn experience.

If the player accepts our request to join the party we can either invite them by:

  • Typing /pcmd add PlayerName
  • Adding them from the search window by selecting their name and confirming "Invite"

Another way to find players for a party is to perform a /yell. Many players may not actively seek a party, but if there is a /yell from a party that they may wish to join they will inform us via a /tell. Depending on the popularity of the sort of party that is being built, we may become inundated with responses. It is typical to invite the first person who responded to your /yell, but if they come in quick succession don't be discouraged from picking the one which best suits your needs. Here's are some examples of yells...

  • Level Sync 33 Zi'Tah pt 3/6 have BRD
  • Mount Z pt 5/6 need healer
  • LF1M Healer's Roll Can I Have It? w/ BRD and COR 5/6

As time goes on you'll find a preferred way of yelling for party members. Remember that /yell is on a 15min. cooldown, so make it count. If you need to do additional yells, party members can be asked to perform a /yell for you. It is best to include a "PST PartyLeader'sName" at the end of the /yell; although, not every player pays attention to this part of the message.

Leading a Party

Being a party leader can be a bit intimidating for new players unfamiliar with the game's meta; however, proactiveness is the best approach to earning experience in FFXI. The basics of party EXP can be quite simple, particularly at early levels. Earlier in this guide we learned how to invite other players to a party, here we will put those methods into use. To begin, each party needs at least one healer, one tank, and someone willing to be a puller. For the last three spots in the party it is best to fill them with damage, preferably at least two melee.

Healers

In the early game, the most effective healer is a White Mage as they have access to spells such as Cure II (Lv.11), Poisona (7), Protectra(7), and Regen (21). Red Mages are capable healers even at level 10 or 11, but parties may find their ability to heal lots of HP in emergency situations a bit lacking until level 14 when they receive Cure II. However, a party with both a White Mage and Red Mage is hardly discouraged as the Red Mage can perform other roles besides healing such as enfeebling and some nuking.

Tanks

Tanks in the dunes are typically a role filled by Warriors as they are the most common. Provoke is Warriors first job ability and through their use of a great axe enmity is easier to maintain early on through damage. Conversely, Paladins are capable of healing themselves, but their ability to maintain enmity or threat on enemies is largely dependent on their pool of MP as Provoke is on a 30-second cooldown. Unless the player playing Paladin is using some form of MP refresh provided by drinks such as Pineapple or Melon Juice, the party may sometimes have to wait for them to recover MP. Ninjas at level 12 gain the use of Utsusemi which provide three shadows that absorb single-target attacks, this makes them a desirable tank for healers and parties because it means less healing and in theory less downtime for a party. Additionally, in the dunes, it helps to have a second provoke whether that's from another Warrior or a melee subbing warrior in the party.

Pullers

Every party needs someone to pull, but few players have the desire to perform this role. It's arguably one of the most active roles in any party as it has the least downtime. That is why it is best to ask a player if they're willing to "pull", as pulling also requires some form of ranged attack. This role often falls to a Thief if they are in the party as their lower damage relative to most other melee means less loss when pulling. Bards usually fill a support role, but can also be the puller of a party, especially after level 24 when it is possible for them to use Ninja as their subjob.

Damage

Due to the game mechanics most parties will prefer for their damage or damage dealers (DD), to be of the melee type. This does not mean we should never invite Black Mages or Summoners. However, in best practice each party may limit themselves to only one or none of these. Black Mages will greatly appreciate it if you assist them in reaching level 20 at which point they will spend most of their time level synced in Qufim. Summoners, capable of some good damage at early levels, would also appreciate the invites and later with the proper party setup they can fill a support/healer role. For melee, two-handed; Dark Knight, Samurai, Dragoon, and Warrior, tend to be preferred and the most common type in places such as the dunes. Other DD include Monk, Blue Mage, and Ranger, the latter of which being the best of the three listed. Monks who are appropriately geared can be good, especially around level 40. Blue Mages unfortunately are dependent on their pool of MP and will require some form of MP refresh to keep in the fight without occasionally resting. Lastly, Puppetmaster and Beastmaster are probably the least desired for party DD.

Support

There are only two dedicated support jobs in FFXI, Bard and Corsair. One sings, the other rolls the dice, literally. Players will desire one or both being in the party, but in the dunes it is never a requirement to earn experience. There aren't always players seeking on these jobs, and if they are they will get gobbled up quickly by other parties. They may even reject our invitation to a dunes party if they are of a sufficient level, typically 55+, as their ability to earn experience is often double what can be achieved in even the best dunes parties.

Alliances

As was mentioned at the beginning of this section, alliances are formed by two to three parties with up to 18 players total. To form an alliance one party leader must request to form one with another party leader. This is done by finding the other party leader, denoted by their name in yellow, in a search window, then select their name and the option to "Form" should appear. If we confirm this option a request to form an alliance will be sent. To accept an alliance formation request, go to your Party menu.

Level Sync

Earlier in this guide Level Sync was mentioned a few times. This system was added to the game in 2008 and is available for use on Eden. Early on in retail Level Sync was limited to players being within 10 levels of one another, on Eden players can level sync from 75 all the way down to 10 if they choose.

How Level Sync Works

One player from the party is chosen as a level sync target. This party member cannot be anonymous or /anon. When level sync is active, the player who is synced to will have a red dot to the right of their name in the party list. All players in the party who are of higher level will be synced down to the same level as the designated sync. Any players who are below the level of the sync will not have their levels raised. After the party has synced to a player, we can begin earning experience. Everyone in the party will earn experience as though they were that level.

To set a level sync target, go into the menu, select Party, select Level Sync, select a player, confirm the prompt that appears. In order to level sync to a player, their current job must be at least level 10.

Note: Power levels will dirty a level synced party's experience if they ever become the focus of the enemy which is being fought. It is possible for them to heal while the party is fighting, but this requires caution to perform well.

In-Game Content

Quests

Unlike modern MMORPGs NPCs will not tell you whether or not they have a quest for you until you've spoken to them. Availability of some quests is dependent upon the player's fame or reputation in that city or region. Several NPCs scattered about the world can be used to help determine player fame.

Active and completed quests can be viewed from the player's Quests menu found under the Missions menu in the main menu.

Missions

Aside from quests there are various sets of missions that contain the main plot of FFXI. These missions often provide the player with rewards that are of significant import.

Nation Missions

Each of the three nations has their own set missions that often intersect with one another. New characters begin the game at Rank 1 and players must complete a set of three missions before being able to reach Rank 2. Achieving higher ranks provides the player with various rewards including an Airship Pass, gil, and custom on Eden, the unlocking of Wardrobe 1 for achieving rank 3. The highest rank for each nation is rank 10, and players are able to switch nations upon which their rank will be back to one. Other than gil previously obtained rewards will not be given again.

To begin completing missions for your nation speak to one of the guards at a gate, guides can be found below:

  • Bastok Missions
  • San d'Oria Missions
  • Windurst Missions
Bonus Conquest Points

From Rank 2 players will be able to trade stacks of crystals to raise their rank bar and obtain hyper efficient conquest points until rank 6. In order to receive bonus conquest points, players must raise their rank bar by trading a specific amount of crystals to a gate guard for each rank. Once the rank bar has been sufficiently raised, extra crystals may be traded one time in exchange for conquest points. To achieve the maximum amount of bonus conquest points it is required that the player must trade eight stacks to the NPC all at once.

  • Rank 2 - Trade 12 crystals to fill the rank bar, then trade 8 stacks of crystals to receive 31,364 conquest points.
  • Rank 3 - Trade 24 crystals to fill the rank bar, then trade 8 stacks of crystals to receive 15,200 conquest points.
  • Rank 4 - Trade 36 crystals to fill the rank bar, then trade 8 stacks of crystals to receive 10,652 conquest points.
  • Rank 5 - Trade 48 crystals to fill the rank bar, then trade 8 stacks of crystals to receive 7,952 conquest points.
  • Rank 6 - Trade 60 crystals to fill the rank bar, then trade 8 stacks of crystals to receive 6,296 conquest points.

Note: If you complete any missions prior to trading crystals, this will raise your rank bar changing the number of crystals required to fill it. It is recommended to trade crystals just after ranking up to avoid issues.

Zilart Missions

Added along with the Rise of the Zilart expansion, the Zilart Missions are a short series of missions that can be completed with relative ease. While these missions go all the way up to 18, players will unlock access to Sky after ZM-12.

Chains of Promathia

Prepare yourself, for cutscenes! Jokes aside, the Chains of Promathia storyline and its missions, beginning with The Rites of Life, is arguably the longest in the game. Coupled with their number and the fact that the majority of these missions include many cutscenes, level capped areas, and battles makes for a long road that requires patience. Progressing through these missions grants players access to new areas and content including ENMs, Lumoria or Sea, Dreamlands Dynamis, and Limbus. Upon completion of the main part of this storyline players will be rewarded with their choice of a ring from a set of three: Tamas Ring, Rajas Ring, and Sattva Ring. These rings can be exchanged one time if the player changes their mind, instructions at the bottom of this section. The complete list of missions can be found here.

Due to their higher degree of difficulty, these missions are typically best tackled by a static group of players. That is why it is best to do one's research before approaching this content. Players will be expected to bring food, medicines, and other consumables that increase the chance of success at winning these battles. Some jobs are quite beneficial to have in this content due to their two hour abilities, SMN, RNG, and WAR. Other jobs which give players a greater advantage include Blue Mage, because of headbutt stun, and Puppetmaster. Both of these jobs came out after this content was released and thus some of their abilities are overpowered.

How to Exchange CoP Rings

Per the guide for CoP Mission 8-4...

  • If a player discards their ring, they will be able to obtain one of the three rings again by revisiting the Marble Bridge in Upper Jeuno. If the ring is discarded a again, one must wait 27 real life days before you will be able to once again choose and obtain another ring.

ToAU Missions

Another relatively lengthy series of missions, there are 44 in total with some Japanese midnight waits in between missions. This storyline and its battles can be quite enjoyable with some decent rewards at the end. All players will begin these missions as part of their basic introduction to Aht Urhgan Whitegate from Naja Salaheem in Salaheem's Sentinels, the mercenary group. Being level 75 is recommended for all missions in Aht Urhgan.

Endgame

The era in which Eden is set possesses a plethora of content to enjoy, especially once it is all available. All of it being released over several years and expansions as part of a horizontal progression system unlike modern MMORPGs a majority of it is all relevant at 75. While gearing a specific job or character players will find themselves partaking in almost every bit of content in the game.

Dynamis

Originally released with the first expansion, Rise of the Zilart, and further expanded upon in the second expansion, Chains of Promathia, Dynamis is the quintessential large group raid content in FFXI. Entry requires having achieved Nation Rank 6 as well as level 65 and visiting Xarcabard for a cutscene. After these requirements are met players can first venture into one of the three city Dynamis zones or Dynamis-Jeuno with any number of players up to 64 or three full alliances every 72 hours. The main goal is to obtain full Outlands access which is first done by obtaining key items from the ???s that appear on the ground where zone bosses were felled in each of the four main zones. This will unlock access to Dynamis - Beaucedine which then must be cleared to access Dynamis - Xarcabard.

Dreamland Dynamis

Released during the Chains of the Promathia expansion period, this content can only be accessed after progressing beyond CoP mission 3-5. There are no other requirements for entering these zones aside from Dynamis - Tavnazia which requires clearing the other three Dreamlands zones. Dreamlands Dynamis areas are noticeably more challenging than their original counterparts as some of the enemies are tougher along with subjob level restrictions at the beginning requiring clearing certain objectives.

HNMs

High-level Notorious Monsters, a source of great controversy for the playerbase during this era of the game. Several HNMs are camped daily by linkshells all competing for claims that are available roughly once per real life day or in some cases every several days. A majority of these special NMs possess drops that are highly sought after by a number of players, but are by no means required to play the game.

Sky

Accessed through completing Zilart mission 12, Tu'Lia or Sky as it is commonly referred to by players was one of the first major pieces of content in FFXI. This region has three zones that are all part of an NM system utilizing pop items all obtained in these areas culminating in players fighting against the god Kirin. Multiple pieces of equipment found in this content are a staple of 75 cap FFXI and are seen as a stepping stone into later content.

Sea

After the long road that is the Chains of Promathia storyline, Lumoria or Sea, uses a similar NM popping system to Sky. Drop rates on several items that are considerably lower compared to Sky and a lack of marketable drops makes Sea less popular with players. However, Sea Torques and various other accessories are still highly sought after, so one may find themselves spending quite a lot of time here.

Limbus

Once players have access to the outside area of Sea they can speak to Sagheera in Port Jeuno to buy a Cosmo Cleanse also known as Soap, to participate in Limbus every 72 hours. This content drops AF upgrade materials and ancient beastcoins used to redeem equipment and upgrade Artifact equipment along with other materials to their +1 versions. If a zone is cleared and the chest opened players will receive one of the items used to challenge Omega or Ultima for a chance at some good equipment.

Assault & Salvage

Assault

Assault is party sized content found in Aht Urghan. Players can first challenge this content after progressing to Aht Urghan mission three and being level 50. Entry is permitted through the possession of an Assault tag, which is given once daily up to three in reserve on the NPC, or four if a player is in possession of the key item as well. Before entering one player in the party must purchase an armband from an NPC inside the staging point for 50 imperial standing points. This player will receive a 10% bonus to their assault points obtained from winning and exiting via the Rune of Release. Attunement to an area's runic portal is required to do assaults there. Only the first two tiers of Assaults are available on Eden at this time.

Nyzul Isle Investigation

Part of assault, Nyzul Isle uses the same assault tag as the other five assault areas. This content consists of multiple floors, 1-100, that are somewhat randomized. Players can climb through the floors while under a time limit and save progress every five levels. Various monsters can be found on each floor, often varying by type, including Notorious Monsters that can drop ??? equipment that have a chance of being appraised into their original open world drops. Every twenty floors players will encounter a floor boss that has a chance to drop some good equipment.

Salvage

Currently not implemented on Eden, Salvage is similar to Assault in some ways, but can be taken on by an alliance of players. However, most players will do this content in small groups, usually one full party. In order to participate in this content players must purchase a Salvage permit with 1500 assault points from one of the five Assault areas.

Upon entering one of the Salvage areas players will be placed with various restrictions that can be removed through the use of specific items found in these areas. How this system works is explained in greater depth on the salvage page. The rewards from Salvage are some of the most desired pieces of equipment in 75-cap FFXI and require a lot of work to obtain.

Progressing through the Game

Unlocking Subjobs

One of the first milestones in FFXI is unlocking the ability to set a subjob. This can be done after reaching level 18 and completing either the quest Elder Memories started in Selbina or The Old Lady which begins in Mhaura. Once one of these quests is completed players will be able to visit a Moogle capable of changing the player's job who will now be able to change the player's subjob.

Advanced Jobs

Upon reaching level 30 players will be able to begin unlocking the advanced jobs. Advanced jobs each have their own individual quests and some require completing multiple prerequisite quests in order to begin the quest which unlocks the job. There are a few advanced jobs that are essentially must haves, especially by the time players reach level 75 and begin tackling endgame. The best way to find information about unlocking a specific job is to open its page on this wiki.

Limit Break

Beginning at level 50, players must visit Maat located in Ru'Lude Gardens every 5 levels to begin their first of several Genkai quests that will remove caps on their ability to earn experience and level. This all culminates in challenging Maat to a fight and defeating him to unlock the ability to level from 70-75. These quests only need to be completed once per character.

Getting Around

There are various methods of traveling around the world of Vana'diel. Acquiring these methods of transportation can take varying amounts of time, but are well worth the effort.

Outpost Warps

Obtained by delivering supplies to the various regional outposts around Vana'diel. Speak to any gate guard from your nation to inquire about delivering supplies to an outpost. Supplies can be picked up once per game day, resetting at midnight. Players can only hold one set of supplies at a time. Only outposts which are located in regions your nation controls through conquest are available for delivery. After delivering supplies to an outpost it becomes available for teleportation in your home nation from one of these respective NPCs:

  • Bastok - Conrad located outside the Moghouse in Bastok Mines K-8.
  • San d'Oria - Jeanvirgaud located outside the Moghouse in Northern San d'Oria L-10.
  • Windurst - Rottata located outside the Moghouse in Port Windurst D-5.

Note: Warping from your home nation to an outpost is restricted by level and varies from one to another. Players must be a minimum of level 10 to use outpost warps. If a region is under beastman control, you will be unable to teleport back to your home nation from that outpost.

Teleportation

White Mage has access to several teleportation spells that can transport themselves and their party members near them to one of the gate crystals; Holla, Dem, Mea, Yhoat, Altep, and Vahzl. In order for a player to be teleported to one of these locations they must first visit the location and examine the crystal to receive a permanent key item.

Warp & Warp II (D2)

Warp is a Black Mage spell available at level 17 that can be cast on oneself to send a player back to their home point. Alternatively, Warp II or D2 as it is more commonly called, is a level 40 Black Mage spell that can be cast on party members.

Escape

Escape is another Black Mage spell this time available at level 29. This spell can only be used in dungeons and will warp the player and any nearby party members out of a dungeon placing them near one of its entrances.

Mounts

In this era the only available mounts were Chocobos, rented from NPCs in cities, Kazham, or any of the teleport locations exlcuding Vahzl. Rideable by characters level 20 or above that have obtained a Chocobo License upon completion of the quest Chocobo's Wounds. This quest requires players to be level 20 and is located at the Chocobo Stables in Upper Jeuno. Players were able to raise their own chocobos in this era, unfortunately, this content has yet to be implemented on any private server due to its complexity.

Note: This quest can take several game days or real life hours to complete (roughly 5 hours).

Airships and Boats/Ferries

There are several different Boats and Airships that players can ride for a 200 gil fee to travel from one destination to another. They all run on a set schedule and take upwards of 15min. for each trip.

Selbina/Mhaura Boat

This boat travels back and forth between Selbina and Mhaura connecting the two main continents of Vana'diel. More importantly this boat gives players from Windurst easier access to the Valkurm Dunes. Accessible to players at any level who pay the fee.

Kazham-Jeuno Airship

Airship that flies from Port-Jeuno to Kazham. This is the only way for players to initially access the areas found in Elshimo. Players must obtain the Airship pass for Kazham key item to ride this airship. This is obtained via the quest Kazham Airship Pass which requires three keys; a Giddeus Chest Key, a Palborough Chest Key, and a Ghelsba Chest Key. Players can bypass this quest by paying a one time fee of 148,000 gil to the same NPC which gives the quest.

Jeuno Airships

The other three airships in Jeuno that are used to fly to the three nations. Players must obtain an Airship pass from reaching Rank 5 in their home nation. Alternatively, players can purchase this key item from Derrick in Lower Jeuno for a fee of 500,000 gil.

Boat to Aht Urhgan

Located in Mhaura this boat takes the player to Aht Urhgan Whitegate. In order to ride this boat players must obtain a Boarding Permit from the quest The Road to Aht Urhgan. Tenshodo membership is required to access the area where the quest NPC Faursel is located in Lower Jeuno. He will give the player several options to complete the quest.

Runic Portals

Teleportation in the Treasures of Aht Urhgan regions. Accessible only after completing and attuning oneself with the respective runic portal located inside each staging point. Visiting the Chamber of Passage in Aht Urhgan Whitegate and purchasing a Runic Portal Use Permit from Sharin-Garin with 200 Imperial Standing will allow the player to teleport to one of the staging points. Possessing an Assault Order will only allow a player to teleport to the Staging Point for that order. Either complete the assault or cancel the orders to allow normal passage through the runic portal.

Items

There are various items that can be used for teleportation around Vana'diel obtained through various means.

  • Scroll of Instant Warp - Warps the player to their home point. Purchased from gate guards for 750 conquest points.
  • Warp Cudgel - Warps the player to their home point. Crafted or purchased from the auction house.
  • Return Ring - Warps the player to the outpost for the region they're in, only if it's under their nations control and they already have done its supplies quest. Purchased with 2,500 conquest points. 10 total charges.
  • Homing Ring - Warps the player to the outpost for the region they're in, only if it's under their nations control and they already have done its supplies quest. Purchased with 9,000 conquest points. 30 total charges.
  • Teleport Rings; Holla Ring, Dem Ring, Mea Ring, Vahzl Ring, Yhoat Ring, Altep Ring - Teleports the player. All rings are level 65.
  • Tavnazian Ring - Teleports the player to the ground floor of Tavnazian Safehold. Obtained by completing CoP Mission 8-1.
  • Olduum Ring - Teleports the player to the Leypoint in Wajaom Woodlands. Obtained from the quest Olduum started by talking to the NPC Dkhaaya at G-9 in Aht Urhgan Whitegate.
  • Ducal Guard's Ring - Teleports the player to Ru'Lude Gardens, cannot be recharged. Obtained after completing CoP Mission 6-4.
  • Maat's Cap - Teleports the player to Maat's location in Ru'Lude Gardens. Challenge and defeat Maat on all of the jobs other than Puppetmaster, Blue Mage, and Corsair.
  • Treat Staff II - Warps the player, useable once per 20 hours, unlimited charges. Obtained via the Halloween Event.

Leveling

After the dunes the number of camps players will explore begins to increase. This guide to EXP camps can be quite useful in finding places to earn experience.

For most jobs standard camps will apply. Certain jobs such as Thief will find it harder to receive invites beyond level 20, which is why many Thieves choose to level in arrowburn parties in places such as Korroloka Tunnel. Black Mages will spend much of their time in Qufim syncing from level 20 to 24.
