Marduk's Jubbah Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A set of armor crafted from various incredibly rare and expensive items, as well as a total of 50 Imperial Gold Pieces. The Marduk Jubbah set is wearable by White Mages, Bards, and Summoners only, and provides large enhancements to MND, CHR, MP, and also provides large Summoning Magic Skill and all White Mage and Bard magic skill bonuses.

Number of Pieces: 5

Cost to store: Storing this armor is not currently possible.
