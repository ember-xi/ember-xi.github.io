Hecatomb Harness Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A flexible set of bone and leather, this set adds truly large amounts of STR, DEX, Attack and Accuracy.
Like every abjuration set, this armor has a downside. In this case, the Hecatomb set has a special trait called Slow. This functions exactly opposite to pieces that say Haste. Every percent slows down melee attacks. Because of this, many players macro the Hecatomb set into Weapon Skills only.
Also see the HQ version, Hecatomb Harness +1 Set.
