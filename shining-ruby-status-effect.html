Level 75 reference · Zenith rules

Description

Shining Ruby is a beneficial status effect that protects from attacks both physical and magical until it wears off or is removed. Benefiting characters receive a 10% boost to both defense and magic defense.

How to remove the effect

  • This effect cannot be removed manually.
  • This effect can be dispelled.

How the effect is inflicted/gained

Job Ability

  • Blood Pact - Shining Ruby (Carbuncle)
