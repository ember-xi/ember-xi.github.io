Trader's Saio Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

This set is statistically identical to the Cotton Dogi Set but usable by many more jobs. This is usually a very expensive set. A base component in the crafting of this set is Red Moko Grass. Since the grass is found through Harvesting only, its price is very high on most servers. The HQ version of this set has the same DEF as the HQ version of the Cotton Dogi Set's HQ version, but better stat bonuses. The high quality version of this set is the Baron's Saio Set.
