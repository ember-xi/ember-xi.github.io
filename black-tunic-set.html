Black Tunic Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A set of upgraded cloth armor for mages and other cloth-wearers, made from linen and velvet. This set is almost purely defensive, although its HQ version has fair bonuses to mage-centric stats. The high quality version of this set is the Mage's Tunic Set.
