Notes:

  • Fished up using a Minnow as bait. Can be fished up with 0 fishing skill.
  • Seems to be slow-moving, so kiting is your best bet if you catch this by accident.
  • An Orobon's lures can be broken by striking it with a critical hit, WS, or JA which attacks it (Weapon Bash, for example). The severing-rate is not 100% for any of the following methods, so if you're after an Orobon Lure, try to land as many critical hits and WSs as possible.
  • Confirmed Skills Used In Combat:
  • Seismic Tail
  • Vile Belch
