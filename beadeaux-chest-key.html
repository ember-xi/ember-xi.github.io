Statistics

Beadeaux chest key
A key that opens a treasure chest in
Beadeaux.

Type: Chest Key

Stackable: Not Stackable

Other Uses

NPC Sell Price: Cannot be sold to NPCs.

Possible Treasure

  • 3,200 - 6,400 gil
  • Adept's Rope
  • Garnet
  • Light Opal
  • Sphene
  • Turquoise

Treasure Maps

Chests on Beadeaux's first map

How to Obtain

Cannot be auctioned, traded, or bazaared, but can be delivered to a character on the same account.
