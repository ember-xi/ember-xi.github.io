Command/timestamp

From Zenith XI Wiki

Level 75 reference · Zenith rules

Please see the Ashita plugin 'Timestamp'.

Aliases: None
Usage: /timestamp [subcommand]
Description: Begins the logout process. Will return you to the character selection screen.
Subcommands:
min Displays timestamps in minutes.
sec Displays timestamps in seconds.
off Hides timestamps in log window.

Toggle on and off when no subcommand is specified.


Notes

  • Timestamps are inserted to the left of applicable lines in the chat log.
  • Timestamps are only displayed for player communication channels.
