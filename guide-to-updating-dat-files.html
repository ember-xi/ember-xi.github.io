FAQs

  • What are .dat files?
    • .dat files are the files the game uses to display things like equipment text. Changes to retail FFXI have made some of the files we use display incorrect information. As these are found they are fixed and put in the .dat repository linked below. One of the first examples people run into would be the WHM spell reraise, in our era the display should say WHM Lv.33 to learn the spell, but base files show it as Lv.25 because at a later time SE lowered the level to learn that spell.


  • Where do I get the most updated .dat files?
    • https://github.com/EdenServer/Eden-Client_DATs


  • How do I update my files?
    • You will download and replace the files in your finalfantasyxi/roms folder.


Click the Green Code button and then Download ZIP

Unzip the file by right clicking on it and extracting all, then move the SquareEnix folder inside to the PlayOnline folder located in Program Files (x86)

Click the "Replace the files in the destination" and you should receive a prompt to replace the files, if you don't you moved them to the wrong place.
