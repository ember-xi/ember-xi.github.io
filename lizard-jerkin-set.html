Lizard Jerkin Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A set of high-defense tanking armor made from hard lizard skins and leathers. This set of armor offers the highest raw defense possible at this level and is ideal for any job that intends to take hits. The high quality version of this set is the Fine Jerkin Set.
