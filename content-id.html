Content ID

From Zenith XI Wiki

Level 75 reference · Zenith rules

Content IDs are, as the name implies, used to manage content on Eden. The user is able to create a Content ID in the Eden Bootloader when they select option 2 and ask for a code to be provided via Eden's discord.
