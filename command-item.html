Command/item

From Zenith XI Wiki

Level 75 reference · Zenith rules

Aliases: None
Usage: /item "[item name]" "[target name]"
Description: Uses an item on a specified target.

You cannot use items that are not in your inventory, or if the current environment restricts usage.

Notes

  • Can be used if the item is a charged equipment, and is currently equipped from a Mog Wardrobe.
