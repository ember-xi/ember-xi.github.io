Statistics

Gusgen chest key
A key that opens a treasure chest in
the Gusgen Mines.

Type: Chest Key

Stackable: Not Stackable

Other Uses

Used in Quest: The Goblin Tailor

NPC Sell Price: Cannot be sold to NPCs.

Possible Treasure

  • 1,980 - 3,600 gil
  • Magical Pattern*
  • Frost Shield
  • Replica Maul
  • Tourmaline
  • Clear Topaz
  • Amber
  • Amethyst
  • Light Opal

* Only available if you have the necessary quest active. Quest items take priority.

Treasure Maps

Chests on Gusgen Mines' first map Chests on Gusgen Mines' second map

How to Obtain

Cannot be auctioned, traded, or bazaared, but can be delivered to a character on the same account.
