Worker Tunica Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A simple set of armor designed to give adventurers doing field work (Harvesting, Logging, and Mining) better success rates. Only the body improves all three results, the other pieces only improve two, so it is important that anyone performing one of these tasks gets the pieces that apply to their task (e.g. a miner would gain nothing from wearing the Worker Hose). This set provides better defense than the Field Tunica Set.


Number of Pieces: 4


Cost to store: Cannot be stored!
