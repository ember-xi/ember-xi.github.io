Bubble Curtain

From Zenith XI Wiki

Level 75 reference · Zenith rules

Reduces magical damage received by 50%
Duration varies by TP
  • 100% TP = 3 Min
  • an additional 45s for each 50% tp
  • Overwrites itself

Description

  • Family: Crab
  • Type: Enhancing
  • Can be dispelled: Yes*
  • Utsusemi/Blink absorb: N/A
  • Range: Self
  • Notes:Nightmare Crabs use an enhanced version that applies a Magic Defense Boost that cannot be dispelled.
