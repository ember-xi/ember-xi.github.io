Brass Harness Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A set of armor that is very ideal for beginner tanks and warrior jobs. Despite being crafted of brass, its appearance is identical to that of the Bronze Harness Set. The high quality version of this set is the Brass Harness +1 Set.
