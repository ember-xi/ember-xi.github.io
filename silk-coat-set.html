Silk Coat Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

A robe set for mages, crafted on a base of silk and velvet and embroidered with silver and gold. This set offers only modest defense for all who can wear such light cloth. The high quality version of this set is the Silk Coat +1 Set.
