Concoction

From Zenith XI Wiki

Level 75 reference · Zenith rules

This special alchemy ability allows you to concentrate ingredients to create medicines in the form of a solid drop. These drops have the same effect as their liquid equivalents.

Key item that is used to make some items within Alchemy.

Needed for Recipes

  • Ether Drop - Alchemy (50)
  • Hi-Ether Drop - Alchemy (69)
  • Hi-Potion Drop - Alchemy (60)
  • Potion Drop - Alchemy (40)

Purchased From

Price: 20,000 Alchemy Guild Points *
Name Location Type
 Hemewmew  Bastok Mines K-7  Guild. Union Rep.

 * Must have an Alchemy skill of 28+ (ie: be a Novice or higher) and you must be signed up to receive Guild Points with the Alchemy Guild.
