Spirit Spell Casting Time

Base Time: 48 seconds
Adjusted by factors:
1. (your Summoning Magic Skill - Max Summoning Magic Skill for your level) / 3
2. Weekday element compared to the spirits element, Strong/Weak +/- 3 seconds
3. Weather element compared to the spirits element, Strong/Weak +/- 2 seconds
4. If Astral FLow is active, -5 seconds

so...
Cast = 48 + ((Skill - MaxSkill) / 3) -- This can add or subtract time.
if Day == (Strong or Weak) then
Cast = Cast +/- 3
if Weather == (Stong or Weak) then
Cast = Cast +/- 2
if Ability Astral FLow then
Cast = Cast - 5

Also some follow up rules.
1. Assault, Retreat, and Disengage reset the casting time to 0
2. A freshly called pet's 1st cast is halved, (Cast/2)
3. An Enhancing spell follow up cast is halved, (Cast/2)
