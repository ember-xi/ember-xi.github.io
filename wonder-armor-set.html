Wonder Armor Set

From Zenith XI Wiki

Level 75 reference · Zenith rules

The cut of this small sized armor set is identical to the level 1 RSE gear every Tarutaru gets for free on a new character. The main difference is instead of green, the color scheme for this set is a soft red. This set makes up for the Tarutaru's shortcoming in melee stats such as HP and STR. It also provides a small boost to VIT and MND.

Unlike Hume and Elvaan, Tarutaru of both genders share the same RSE set.
